## 🔄 방법 2: MS Word 경유 변환

### 장점
- Pandoc으로 빠른 초기 변환
- 익숙한 MS Word 환경에서 편집

### 단점
- 테이블 구조가 완벽하지 않을 수 있음
- Word → 한글 변환 시 레이아웃 깨질 수 있음
- 수동 조정 필요

### 절차

#### 1. Pandoc 설치 (이미 설치되어 있다면 생략)

```bash
# macOS
brew install pandoc

# Ubuntu/Debian
sudo apt-get install pandoc

# Windows
# https://pandoc.org/installing.html 에서 설치
```

#### 2. Markdown → Word 변환

```bash
cd /Users/jiookcha/Documents/git/AI-CoScientist/output

pandoc K-NeuroMind_Korean_Government_Proposal.md \
       -o K-NeuroMind_Proposal.docx \
       --toc \
       --toc-depth=3 \
       --highlight-style=tango \
       -V geometry:margin=1in
```

#### 3. MS Word에서 편집

1. `K-NeuroMind_Proposal.docx` 열기
2. 스타일 적용:
   - 제목 1: 14pt, 굵게
   - 제목 2: 12pt, 굵게
   - 본문: 10pt, 맑은 고딕
3. 테이블 포맷팅:
   - 테두리 1pt
   - 셀 패딩 2mm
   - 헤더 행 회색 배경 (10%)
4. 페이지 번호 삽입
5. 목차 업데이트

#### 4. 한글로 가져오기

1. 한글 프로그램 실행
2. 파일 > 불러오기 > MS Word 문서
3. `K-NeuroMind_Proposal.docx` 선택
4. 가져오기 옵션:
   - ☑ 스타일 유지
   - ☑ 표 구조 유지
   - ☑ 이미지 포함
5. 확인 클릭

#### 5. 한글에서 조정

1. grant.hwpx 템플릿과 비교
2. 테이블 구조 맞추기:
   - 셀 병합/분리
   - 너비 조정
   - 테두리 스타일
3. 퍼센티지 셀 수식 확인
4. 예산 테이블 합계 수식 확인

#### 6. 저장

```
파일 > 다른 이름으로 저장 > .hwpx 형식
```

**예상 소요 시간**: 1시간 30분 - 2시간

## 📞 문제 해결 FAQ

### Q1: 테이블이 깨져서 나옵니다

**A**: 한글에서 직접 테이블을 재생성하세요.
- 표 > 표 만들기
- 행/열 개수 설정
- 셀 병합/분리

### Q2: 퍼센티지 합계가 100%가 안 됩니다

**A**: 수동으로 재계산하세요.
- 데이터 수집 방법: 20 + 10 + 50 + 20 = 100
- 데이터 전처리: 25 + 25 + 25 + 25 = 100
- AI 모델 개발: 50 + 15 + 15 + 10 + 10 = 100

### Q3: 예산 합계가 맞지 않습니다

**A**: 엑셀에서 검증 후 재입력하세요.
```
연도별 총계:
'26: 500+200+300+50+550 = 1,600 ✓
'27: 600+250+400+100+530 = 1,880 ✓
'28: 400+200+500+150+950 = 2,200 ✓
'29: 200+50+400+200+1,515 = 2,365 ✓
'30: 100+50+300+250+1,388 = 2,088 ✓

총계: 1,600+1,880+2,200+2,365+2,088 = 10,133 ✓
```

### Q4: 한글에서 파일이 안 열립니다

**A**: 한글 버전 확인

### Q5: 페이지 수가 너무 많이 나옵니다

**A**: 다음을 조정하세요:
- 줄 간격: 160% → 150%
- 폰트 크기: 10pt → 9pt
- 여백: 25mm → 20mm
- 테이블 셀 패딩 축소
