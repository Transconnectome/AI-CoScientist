# 논문/제안서 리뷰 스킬 (paper-review)

## 개요
AI-CoScientist의 4차원 평가 시스템을 활용하여 논문 및 연구 제안서를 체계적으로 분석하고 개선점을 도출하는 스킬입니다.

---

## 🎯 평가 프레임워크

### 4차원 품질 평가 (AI-CoScientist 기준)

| 차원 | 평가 기준 | 가중치 |
|------|----------|--------|
| **Novelty (독창성)** | 새로운 아이디어, 기존 연구와의 차별점, First Mover 가치 | 25% |
| **Methodology (방법론)** | 연구 설계, 데이터 품질, 분석 방법의 적절성 | 30% |
| **Clarity (명확성)** | 논리 구조, 문장 가독성, 그림/표 품질 | 20% |
| **Significance (중요성)** | 학문적/사회적 영향력, 실용성, 확장 가능성 | 25% |

### 점수 기준
- **9.0+**: 출판/수주 가능 수준
- **8.0-8.9**: 약간의 수정 후 제출 가능
- **7.0-7.9**: 중간 수준의 개선 필요
- **6.0-6.9**: 상당한 수정 필요
- **6.0 미만**: 대폭 재작성 필요

## 📋 섹션별 리뷰 체크리스트

### 1. 제목 (Title)
- [ ] 핵심 키워드 포함 (3-5개)
- [ ] 연구 범위 명확히 전달
- [ ] 독창성/차별성 암시
- [ ] 적절한 길이 (15단어 이하)

### 2. 초록 (Abstract)
- [ ] 연구 배경/필요성 (1-2문장)
- [ ] 연구 목적 명시
- [ ] 핵심 방법론 요약
- [ ] 주요 결과/기대효과
- [ ] 250단어 이내

### 3. 서론 (Introduction)
- [ ] 연구 분야 현황 및 문제점
- [ ] 기존 연구의 한계점 명시
- [ ] 연구 질문/가설 명확화
- [ ] 연구의 독창적 기여점
- [ ] 논문 구조 안내 (선택)

### 4. 방법론 (Methods)
- [ ] 연구 설계 타당성
- [ ] 데이터 수집 방법 상세 기술
- [ ] 분석 방법 적절성
- [ ] 재현 가능성 (코드, 데이터 공개 계획)
- [ ] 윤리적 고려사항 (IRB 등)

### 5. 결과/기대효과 (Results)
- [ ] 정량적 지표 제시
- [ ] 시각화 자료 품질
- [ ] 통계적 유의성 명시
- [ ] 기대 성과 현실성

### 6. 논의/결론 (Discussion)
- [ ] 결과의 의미 해석
- [ ] 기존 연구와의 비교
- [ ] 연구 한계점 인정
- [ ] 향후 연구 방향
- [ ] 학문적/사회적 기여

## 🏢 삼성미래기술육성사업 특화 체크리스트

### High Risk - High Return 평가

| 항목 | 체크 | 설명 |
|------|------|------|
| **파괴적 혁신** | [ ] | 기존 패러다임을 바꿀 수 있는가? |
| **세계 최초/최고** | [ ] | First Mover 가치가 있는가? |
| **높은 불확실성** | [ ] | 도전적이지만 달성 가능한가? |
| **큰 파급효과** | [ ] | 성공 시 영향력이 큰가? |
| **융합 연구** | [ ] | 다학제적 접근인가? |

### 삼성 평가 위원 관점

```
✅ 반드시 포함해야 할 요소:
- "세계 최초" 또는 "국내 최초" 표현
- 정량적 목표 (수치로 제시)
- 경쟁 기술 대비 우위 (표로 비교)
- 연구팀 역량 (실적 기반)
- 실패 시 대안 (Plan B)

❌ 피해야 할 요소:
- 모호한 표현 ("~할 예정", "~할 것으로 기대")
- 과도한 약속 (검증 없는 주장)
- 기존 연구 단순 확장
- 경쟁사 언급 없음
```

## 🔄 AI-CoScientist 연동

### 자동 개선 루프 (Phase 4)
```bash
# 대화형 리뷰어 실행
python scripts/chat_reviewer_enhanced.py

# 명령어:
# /versions - 버전 히스토리
# /suggest - RAG 기반 개선 제안
# /iterate 8.5 - 목표 점수까지 자동 개선
# /compare 1.0.0 1.2.0 - 버전 비교
# /analytics - 개선 분석
```

### API 활용
```python
# 논문 평가
POST /api/v1/papers/{paper_id}/analyze

# 스마트 제안
GET /api/v1/improvements/{paper_id}/suggestions/smart

# 자동 개선
POST /api/v1/improvements/{paper_id}/iterate
{
    "target_score": 8.5,
    "max_iterations": 5
}
```
