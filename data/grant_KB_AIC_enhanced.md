### 2.1 AI 모델 학습을 위한 데이터 수집 및 전처리

#### < 데이터 수집 방법 >

| 데이터 확보 방안 | 설명 | 중복선택 |
|---------------|------|---------|
| 데이터 신규 구축 | AI 학습을 위해 데이터를 처음부터 새롭게 수집·가공하는 방식 | 20% |
| 기존 데이터 확장 | 기존 데이터셋에 새로운 데이터를 추가하여 확장하는 방식 | 10% |
| 기 구축된 타기관 데이터 활용 | 정부, 연구기관, 기업 등에서 기 구축 데이터셋을 활용하는 방식 | 50% |
| 기 구축된 자체 데이터 활용 | 보유한 기존 데이터를 가공하여 AI학습에 활용하는 방식 | 20% |
| 기타 | 위 4가지 항목에 해당하지 않는 경우 | |

**데이터 출처·종류·확보방안 등 선택 항목 관련 주요설명:**

- **데이터 종류**: 이미지(fMRI, dMRI), 시계열(EEG, SEEG), 정형(임상 데이터), 비정형(행동 데이터)
- **데이터 수집 방법**: 주요 대학병원 이미징 센터에서 fMRI, dMRI, SEEG 등 수집
  - 서울대병원, 아산병원, 삼성서울병원 등 5개 거점 병원 협력 체계 구축
  - 표준화된 촬영 프로토콜 적용을 통한 데이터 품질 보증
  - IRB 승인 기반 윤리적 데이터 수집
- **데이터 신규 구축**: 약 1천건, 약 1,500백만원('26~'28)
  - 다양한 연령대(20~80세) 및 질환군 포함
  - 종단 데이터(longitudinal data) 수집을 통한 뇌 변화 추적
- **기존 데이터 활용 시 재가공 비용**: 약 500백만원
  - 기존 데이터의 표준화 및 품질 관리
  - 익명화 처리 및 개인정보 보호 조치
  - 데이터 통합 플랫폼 구축

**[국민 데이터 주권 및 윤리적 데이터 활용]**
- 모든 데이터 수집은 엄격한 개인정보 보호 절차를 거쳐 진행되며, 참여자의 자발적 동의를 전제로 합니다
- 수집된 데이터는 한국 내 안전한 서버에 보관되어 국민 건강 데이터 주권을 확보합니다
- 연구 참여자에게는 개인 뇌 건강 리포트를 제공하여 조기 질환 발견 기회를 제공합니다

**데이터전처리 관련 세부 연구내용 기술:**

**1. 데이터 기초 전처리 (25%)**
- fMRI/dMRI 영상 데이터 품질 검증 및 아티팩트 제거
- EEG/SEEG 신호 전처리: 노이즈 제거, 필터링, 기준선 보정
- 임상 데이터 정규화 및 결측치 처리
- 비용: 약 250백만원 (전문 인력 5명 x 1년)

**2. 데이터 증강 및 변환 적용 (25%)**
- fMRI 영상 증강: 회전, 플립, 강도 조정을 통한 데이터셋 확장
- 뇌 영역 간 기능적 연결성 그래프 변환
- 시계열 데이터 증강: 노이즈 추가, 시간 왜곡을 통한 robust 모델 학습
- 비용: 약 300백만원 (고성능 컴퓨팅 자원 활용 포함)

**3. 대량데이터 자동처리 및 최적화 (25%)**
- AI 기반 자동 라벨링 시스템 구축: 뇌 영역 자동 분할 및 질환 분류
- 불균형 데이터 처리: SMOTE, ADASYN 등 샘플링 기법 적용
- 분산 데이터 처리 시스템 구축: Apache Spark 기반 대용량 데이터 처리
- 비용: 약 400백만원 (인프라 구축 및 개발 비용)

**4. 실시간 데이터 품질 관리 및 지속적인 갱신 (25%)**
- 데이터 파이프라인 자동화: Airflow 기반 ETL 프로세스 구축
- 실시간 품질 모니터링 대시보드 개발
- 데이터 드리프트 감지 시스템: 지속적인 모델 성능 모니터링
- 비용: 약 350백만원 (시스템 개발 및 운영 비용)

**총 데이터 전처리 비용: 1,300백만원**

### 🎯 AI 기술 활용의 국가적 의의

본 사업은 단순한 AI 기술 개발을 넘어, **국가 보건의료 주권 확보**와 **AI 헬스케어 산업 생태계 구축**을 통해 대한민국의 AI 경쟁력을 실질적으로 강화하는 전략 사업입니다.

#### 1️⃣ **기술 주권 확보 및 서구 의존도 탈피**

**현실**: 현재 의료 AI는 서구 중심 데이터와 알고리즘에 의존
- 글로벌 뇌 AI 모델은 주로 백인 중심 데이터(UK Biobank, ADNI 등)로 학습
- 한국인 뇌 특성 (두개골 형태, 유전적 특이성, 질환 양상) 미반영
- 해외 AI 기업 의존 시 **기술 종속** 및 **데이터 유출** 위험

**본 사업의 해결책**:
- **한국인 특화 브레인 파운데이션 모델** 개발로 원천기술 확보
- **국내 데이터, 국내 서버, 국내 모델** 3원칙 수립
- 서구 중심 AI의 한계를 극복하고 아시아 표준 선도
- **데이터 주권**: 국민 건강정보를 국내에서 안전하게 관리

**1. 신규모델 개발 (45%) - 핵심 전략**

본 사업은 뇌 영상 분석에 최적화된 **완전히 새로운 AI 아키텍처**를 설계하고 개발합니다. 기존 범용 AI 모델의 한계를 극복하고, 뇌의 복잡한 특성을 정확히 모델링하는 **도메인 특화 신경망**을 구축합니다.

**1-1. 시공간 뇌영상 분석 모델**

뇌 영상 데이터의 핵심은 **시간과 공간이 동시에 변화**하는 복잡한 패턴입니다. 본 사업은 이러한 4차원적 특성을 포착하는 신규 모델을 개발합니다.

- **4차원 Transformer 기반 아키텍처**:
  - 기존 3D CNN이 놓치는 **시간적 역학(temporal dynamics)**을 4D attention 메커니즘으로 포착
  - fMRI 시계열을 '뇌 활동 비디오'로 처리하여 동적 연결성(dynamic connectivity) 학습
  - 시간적 주의(temporal attention)와 공간적 주의(spatial attention)를 분리 설계하여 학습 효율성 극대화

- **한국인 뇌 데이터 최적화**:
  - 한국인 뇌 해부학적 특성(뇌 영역 크기, 백질 분포)을 반영한 모델 파라미터 조정
  - 건강한 한국인 1,000명 데이터로 자기지도학습 수행하여 한국형 기준 모델 확립
  - **성능 목표**: 알츠하이머 조기 진단 정확도 90% 달성 (기존 78% 대비 12%p 향상)

**1-2. 멀티모달 통합 학습 모델**

뇌질환 진단은 뇌 영상만으로는 불충분하며, 유전자 정보와 임상 데이터를 통합 분석해야 합니다. 본 사업은 이질적 데이터를 통합하는 신규 아키텍처를 개발합니다.

- **통합 표현 학습 (Unified Representation Learning)**:
  - 뇌 영상(fMRI, dMRI, EEG) + 유전자(APOE, BDNF) + 임상 데이터(혈압, 혈당, 인지 점수)를 단일 임베딩 공간으로 통합
  - 서로 다른 데이터 타입(영상, 숫자, 범주)을 효과적으로 융합하는 attention 메커니즘 개발
  - Contrastive learning으로 모달리티 간 공통 표현 학습

- **한국인 특화 위험 인자 모델링**:
  - APOE 유전자 변이와 뇌 영상 패턴의 상관관계 학습
  - 한국인 고유 위험 인자(고혈압, 당뇨, 식습관)를 통합 모델링
  - **성능 목표**: 10년 후 치매 발병 위험 예측 정확도 85% (조기 개입 가능)

**1-3. 효율적 장시간 뇌신호 처리 모델**

EEG/SEEG는 초당 수백~수천 개의 데이터 포인트를 생성하여, 8시간 수면 분석 시 수백만 개의 시계열 데이터가 발생합니다. 기존 Transformer는 메모리와 연산량 문제로 처리가 불가능합니다.

- **선형 복잡도 시퀀스 모델**:
  - 기존 Transformer의 O(n²) 복잡도를 O(n) 선형 복잡도로 개선한 신규 아키텍처 개발
  - 중요한 뇌 활동 패턴에만 집중하는 선택적 메모리 메커니즘(selective attention) 구현
  - 장시간 데이터에서도 실시간 분석이 가능한 효율적 모델 구조

- **임상 적용**:
  - 장시간 수면 EEG 분석 (8시간 연속 데이터 처리)
  - 간질 발작 예측 (SEEG 신호 패턴으로 30분 전 예측, 정확도 80% 목표)
  - 실시간 뇌-컴퓨터 인터페이스 (저지연 반응 시간 <100ms)

**1-4. 뇌 연결망 분석 모델**

뇌는 100개 이상의 영역이 복잡하게 연결된 네트워크입니다. 알츠하이머와 같은 퇴행성 질환은 이 연결망이 점진적으로 붕괴되는 과정이므로, 연결망 분석이 조기 진단의 핵심입니다.

- **동적 그래프 신경망 (Dynamic Graph Neural Network)**:
  - 뇌 영역(node)과 영역 간 연결성(edge)을 동시에 학습하는 그래프 모델
  - 시간에 따라 변하는 뇌 연결망 패턴을 포착하는 동적 그래프 학습
  - 한국인 표준 뇌 연결망 구축: 한국인 건강 기준(normative model) 확립

- **임상 적용**:
  - 알츠하이머 환자의 뇌 연결망 붕괴 패턴 조기 감지 (발병 5-10년 전)
  - 파킨슨병 환자의 운동 네트워크 이상 탐지
  - 우울증 환자의 감정 조절 네트워크 분석

**1-5. 뇌 파운데이션 모델 (Brain Foundation Model)**

대규모 사전학습 모델(Foundation Model)은 소량의 데이터로도 높은 성능을 달성할 수 있어, 희귀 뇌질환 진단에 필수적입니다.

- **대규모 자기지도학습 (Self-Supervised Learning)**:
  - 레이블 없는 건강인 데이터 10,000명으로 뇌 표현(brain representation) 사전학습
  - 사전학습 후 소량의 환자 데이터(100-200명)로 빠른 fine-tuning 가능
  - 다양한 뇌질환에 범용적으로 적용 가능한 기초 모델 구축

- **병원 간 호환성 보장**:
  - 서로 다른 병원의 MRI 기기, EEG 전극 배치에도 적용 가능한 robust 모델
  - 개인 간 뇌 신호 변동성을 극복하는 일반화 능력 확보
  - **성능 목표**: 새로운 병원 데이터에서도 90% 이상 성능 유지

**핵심 차별성: 왜 신규모델 개발이 필수인가?**

1. **뇌의 4차원 복잡성**: 기존 2D/3D 모델로는 시간에 따른 뇌 활동 변화를 포착할 수 없어, 시공간 통합 모델 개발 필수
2. **한국인 특화 필요성**: 서구 데이터로 학습한 모델은 한국인 뇌에서 15-20% 성능 저하 발생 (인종 간 뇌 구조 차이)
3. **멀티모달 통합**: 영상+유전자+임상 데이터를 통합하는 기존 AI 모델 부재, 새로운 아키텍처 개발 필수
4. **장시간 데이터 처리**: 기존 Transformer는 8시간 EEG 데이터 처리 불가능, 선형 복잡도 모델 개발 필수
5. **기술 주권**: 해외 기술 의존 탈피, 국내 독자 개발로 국가 안보 및 산업 경쟁력 확보

**2. 새로운 알고리즘 개발 (30%) - 학습 효율성 극대화**

**2-1. 자기지도학습 기반 대규모 사전학습**

의료 데이터는 레이블(진단 정보) 획득 비용이 매우 높습니다. 자기지도학습은 레이블 없이도 데이터의 내재된 패턴을 학습할 수 있어, 대규모 뇌 데이터 활용의 핵심 기술입니다.

- **마스킹 복원 기반 사전학습**:
  - 뇌 영상의 일부를 임의로 숨기고, 주변 정보로부터 복원하도록 학습
  - 레이블 없는 건강인 데이터 10,000명으로 뇌의 정상 패턴 학습
  - 사전학습 후 소량의 환자 데이터(100-200명)로 질환별 fine-tuning
  - **효과**: 데이터 효율성 10배 향상 (기존 1,000명 필요 → 100명으로 가능)

- **대조 학습 기반 멀티모달 정렬**:
  - 같은 환자의 서로 다른 모달리티(fMRI-EEG 쌍)를 가깝게, 다른 환자는 멀게 배치
  - 한 모달리티가 부족해도 다른 모달리티로 보완 가능한 유연한 시스템 구축
  - **응용**: MRI 촬영이 어려운 환자도 EEG만으로 진단 가능

**2-2. 소량 데이터 학습 알고리즘**

희귀 뇌질환은 연간 10-50명만 발생하여, 기존 딥러닝으로는 학습이 불가능합니다. 소량 데이터 학습 알고리즘은 5-10명의 데이터만으로도 새로운 질환을 학습할 수 있습니다.

- **메타학습 (Meta-Learning)**:
  - "학습하는 방법을 학습"하여, 새로운 질환에 빠르게 적응
  - 여러 뇌질환에서 공통 학습 패턴을 추출하여 일반화 능력 확보
  - 5-10명 데이터로 새로운 희귀질환 분류 가능
  - **성능 목표**: 희귀질환 진단 정확도 75% (기존 40% 대비 35%p 향상)

- **프로토타입 기반 학습**:
  - 각 질환의 '대표 패턴(프로토타입)' 학습
  - 새로운 환자를 가장 가까운 프로토타입으로 분류
  - **응용**: 미지의 뇌종양 아형 자동 분류, 드물게 나타나는 뇌질환 패턴 탐지

**2-3. 불확실성 정량화 알고리즘**

의료 AI는 "얼마나 확신하는가"를 명시해야 의사가 신뢰할 수 있습니다. 불확실성 정량화는 AI의 예측이 얼마나 신뢰할 만한지를 수치로 제공합니다.

- **확률적 딥러닝 (Probabilistic Deep Learning)**:
  - 단일 예측값이 아닌 확률 분포로 결과 제공
  - "이 환자는 알츠하이머 확률 85% ± 5%" 형태로 불확실성 명시
  - 낮은 신뢰도의 경우 추가 검사 권고 → 오진 방지
  - **목표**: 의사의 신뢰 기반 의사결정 지원, 의료 사고 위험 감소

- **통계적 보장 예측**:
  - 수학적으로 보장된 예측 구간 제공
  - "95% 확률로 이 환자의 인지 점수는 20-25점 사이" 보장
  - **규제 대응**: 의료기기 인허가 시 안전성 입증 필수 요건

**2-4. 효율적 대규모 학습 알고리즘**

뇌 영상 AI는 수십억 개의 파라미터를 가진 대규모 모델이 필요하나, 단일 GPU로는 학습에 수개월이 소요됩니다. 효율적 학습 알고리즘으로 학습 시간을 대폭 단축합니다.

- **분산 병렬 학습 최적화**:
  - 64개 GPU를 활용한 분산 학습으로 학습 시간 1/50 단축 (2주 → 1일)
  - 대규모 모델(10억 파라미터)도 현실적 시간 내 학습 가능
  - **효과**: 연구 개발 주기 단축, 빠른 모델 개선 및 검증 가능

- **메모리 효율적 학습**:
  - 혼합 정밀도 학습(Mixed Precision)으로 메모리 사용량 50% 절감
  - 동일 하드웨어로 2배 큰 모델 학습 가능 또는 배치 크기 2배 증가
  - **효과**: 하드웨어 투자 비용 절감, 학습 안정성 향상

**3. 오픈모델 활용 (15%) - 검증된 기술 활용**

- **Vision Transformer (ViT) Fine-tuning**:
  - ImageNet 사전학습 모델 → 뇌 MRI 영상 분석 전이학습
  - **활용**: 뇌종양 segmentation, 뇌위축 정량화

- **BERT for Clinical Text Analysis**:
  - 의료 기록 자동 분석 및 위험 인자 추출
  - **활용**: 전자의무기록(EMR)에서 치매 위험 인자 자동 스크리닝

- **CLIP for Brain-Behavior Alignment**:
  - 뇌 영상과 행동 설명(텍스트)을 공통 임베딩으로 학습
  - **활용**: "기억력 감퇴" 증상을 가진 환자의 뇌 영상 패턴 자동 매칭

**4. 선행사업 모델 활용/개선 (5%)**

| **발작 시작 영역 (SOZ) 로컬라이제이션** | Precision / Recall | P=0.65, R=0.70 | P=0.85, R=0.90 | 수술 성공률 직접 결정 (SOZ 완전 절제 시 70-80% 발작 소실) |

| **간질 병변 식별** | F1-score | 0.68 | 0.88 | MRI 음성 간질 환자 (30%) 진단 |

**핵심 도전**: 간질 환자의 약 30%는 MRI에서 병변이 보이지 않습니다 (MRI-negative epilepsy). SEEG/iEEG 데이터를 AI로 분석하여 **미세 병변**을 찾아내면 수술 가능 환자가 증가합니다.

**AI 모델 평가 프로토콜**:
- 훈련 데이터: 200명 환자 SEEG 데이터 (수술 결과로 검증)
- 평가 지표: 수술 후 1년 발작 소실률(Engel Class I)과의 상관관계
- 목표: AI 예측 SOZ와 실제 수술 성공 부위 일치도 85% 이상

#### **5-2. 발작 예측 및 조기 경고 (Seizure Prediction)**

| 평가 과제 | 평가 지표 | 기존 성능 | 목표 성능 | 임상적 의의 |
|---------|---------|----------|----------|----------|
| **발작 30분 전 예측** | Sensitivity / FPR* | Sens=0.65, FPR=0.3/h | Sens=0.85, FPR=0.1/h | 조기 약물 복용, 안전 확보 |
| **발작 시작 실시간 감지** | Detection Latency | 8초 | 2초 | 신경 자극 치료 (RNS) 최적화 |
| **발작 간 HFO** 탐지 | Detection Rate | 0.72 | 0.90 | 장기 모니터링으로 병변 추적 |

*FPR (False Positive Rate): 시간당 허위 경보 횟수

**고주파 진동 (HFO, 80-500 Hz)**: 간질 병변의 바이오마커로, 발작이 없을 때도 측정 가능합니다. AI로 HFO를 자동 탐지하면 **24시간 장기 모니터링**이 가능하여 진단 정확도가 향상됩니다.

**AI 모델 평가 프로토콜**:
- 훈련 데이터: 100명 환자의 장기 iEEG 데이터 (총 5,000시간 이상)
- 평가 지표: Time-to-detection, False alarm rate (시간당 0.1회 이하)
- 임상 검증: 실제 환자 대상 전향적 검증 (prospective validation)

#### **5-3. 뇌-컴퓨터 인터페이스 (Brain-Computer Interface, BCI)**

| 평가 과제 | 평가 지표 | 기존 성능 | 목표 성능 | 임상적 의의 |
|---------|---------|----------|----------|----------|
| **운동 의도 디코딩** | Classification Accuracy | 0.78 | 0.92 | 마비 환자 로봇 팔 제어 |
| **언어 생성 디코딩** | Word Error Rate (WER) | 35% | 15% | ALS 환자 의사소통 복원 |
| **정보 전달 속도 (ITR)** | bits/min | 25 | 60 | 실용적 의사소통 속도 |

**운동 의도 디코딩**: 운동 피질(motor cortex)의 ECOG 신호로부터 손가락 움직임, 팔 움직임 의도를 실시간으로 해독하여 **로봇 팔 또는 커서 제어**에 활용합니다. 척수 손상, ALS 환자에게 직접적 혜택을 제공합니다.

**언어 디코딩**: 브로카 영역(Broca's area) 및 운동 피질의 ECOG 신호로부터 **말하려는 단어**를 직접 디코딩합니다. 발성 불가능한 환자(locked-in syndrome)의 의사소통을 복원합니다.

**AI 모델 평가 프로토콜**:
- 훈련 데이터: 30명 ECOG 데이터 (운동 과제 수행 중)
- 평가 지표: Real-time decoding accuracy, Information transfer rate (ITR)
- 임상 검증: 실제 마비 환자 대상 로봇 팔 제어 성공률

#### **5-4. 기능 매핑 및 수술 안전성 (Functional Mapping)**

| 평가 과제 | 평가 지표 | 기존 성능 | 목표 성능 | 임상적 의의 |
|---------|---------|----------|----------|----------|
| **언어 영역 자동 식별** | Concordance with ESM* | 0.72 | 0.90 | 수술 중 언어 기능 보존 |
| **기억 영역 예측** | Prediction Accuracy | 0.68 | 0.85 | 해마 절제 후 기억 손상 예방 |
| **수면 단계 고해상도 분류** | Micro-arousal Detection | 0.75 | 0.92 | 수면 장애 정밀 진단 |

*ESM (Electrical Stimulation Mapping): 전기 자극을 통한 뇌 기능 매핑 (임상 표준)

**언어 영역 매핑**: 간질 수술 시 언어 영역(브로카, 베르니케)을 보존해야 합니다. 기존에는 수술 중 환자를 깨워 전기 자극 매핑(ESM)을 했지만, AI로 SEEG 데이터만으로 **사전 예측**이 가능하면 수술 시간 단축 및 환자 부담 감소가 가능합니다.

**AI 모델 평가 프로토콜**:
- 훈련 데이터: 50명 환자의 SEEG + ESM 결과 (ground truth)
- 평가 지표: AI 예측 언어 영역과 ESM 결과의 일치도 (Dice coefficient)
- 임상 검증: 수술 후 언어 기능 보존률 평가

**기대 효과**:
- 간질 환자 수술 성공률 70% → 85% 향상
- 발작 조기 경고로 연간 낙상 사고 30% 감소
- 마비 환자 100명에게 로봇 팔 제어 기술 제공
- 뇌 수술 중 기능 손상 위험 50% 감소

**핵심 문제 인식: 표준화된 평가 체계의 부재**

현재 뇌 AI 연구는 **각 연구마다 다른 데이터셋, 다른 평가 방식**을 사용하여 결과 비교가 불가능하고, 연구 재현성이 낮습니다. NLP 분야의 GLUE/SuperGLUE, 컴퓨터 비전 분야의 ImageNet처럼, **표준화된 벤치마크의 존재**가 해당 분야의 폭발적 발전을 이끌었습니다.

본 사업은 뇌 파운데이션 모델의 성능을 종합적으로 평가할 수 있는 **한국형 표준 벤치마크 (K-Brain Benchmark Suite)**를 구축합니다. 이는 **단순한 데이터 수집이 아닌, 뇌-인지-행동의 다층적 관계를 체계적으로 매핑하는 핵심 연구 개발 과제**입니다.

### **2. 다층적 데이터 통합: 뇌-인지-행동 연결 매핑**

뇌 파운데이션 모델의 진정한 가치는 **뇌 영상 → 인지 상태 → 행동 결과**의 전체 경로를 모델링할 수 있는가에 달려 있습니다.

**Level 1: 뇌 구조/기능 데이터**
- T1 MRI (해부학), fMRI (기능), dMRI (연결성), EEG (신경 진동)
- 3,000명 × 4 모달리티 = 12,000 스캔

**Level 2: 인지 평가 데이터**
- 신경심리검사: K-MMSE, MoCA, WAIS (지능), K-TMT (집행기능)
- 인지 과제: N-back (작업기억), Stroop (억제), CPT (주의)
- 3,000명 × 평균 8개 검사 = 24,000 인지 점수

**Level 3: 행동/임상 데이터**
- 실생활 기능: ADL, IADL (일상생활 능력)
- 정서 상태: Beck Depression Inventory, State-Trait Anxiety
- 유전자 정보: APOE, BDNF 등 10개 SNP
- 혈액 바이오마커: Aβ42, tau, NfL

**Level 4: 종단 추적 데이터**
- 2년간 연간 재촬영 (연도 0, 1, 2)
- 인지 재평가 (6개월마다)
- 총 3,000명 × 3 시점 = 9,000 종단 데이터

**핵심 도전 과제**: 이 4개 레벨을 **일관되게 연결**하는 데이터 구조 설계. 예를 들어, "해마 위축 (Level 1) → 기억력 저하 (Level 2) → 일상생활 어려움 (Level 3) → 2년 후 MCI 진행 (Level 4)" 경로를 추적 가능해야 합니다.

### **3. 기술적 난제와 해결 방안**

#### **Challenge 1: 데이터 이질성 (Heterogeneity)**
- **문제**: 5개 거점 병원, 서로 다른 MRI 기기 (Siemens, GE, Philips), 다른 촬영 프로토콜
- **해결**:
  - 표준화된 촬영 프로토콜 수립 (ADNI 프로토콜 참조, Weiner et al., 2013)
  - ComBat harmonization 알고리즘 적용 (scanner 효과 제거)
  - Multi-site validation: 각 병원 데이터로 별도 평가

#### **Challenge 2: 레이블 일관성 (Label Consistency)**
- **문제**: 같은 환자를 다른 의사가 다르게 진단 (inter-rater reliability ~0.7)
- **해결**:
  - 다중 전문가 합의 프로토콜 (최소 3명 의사 독립 평가)
  - 객관적 바이오마커 기준 (amyloid PET, CSF biomarker)
  - 명확한 진단 기준 (DSM-5, NIA-AA criteria)

#### **Challenge 3: 결측 데이터 (Missing Data)**
- **문제**: 환자 A는 fMRI만, 환자 B는 EEG만 → 멀티모달 평가 불가
- **해결**:
  - 모달리티별 독립 평가 + 멀티모달 통합 평가 (두 가지 track)
  - Imputation 알고리즘: 한 모달리티로 다른 모달리티 예측
  - Flexible evaluation: 최소 2개 모달리티만 있어도 평가 가능

#### **Challenge 4: 벤치마크 과적합 방지**
- **문제**: Test set 공개 → 모델이 test set에 과적합 → 실제 성능 과장
- **해결**:
  - Hold-out test set 영구 비공개 (500명)
  - 정기적 test set 갱신 (매년 100명 추가)
  - Leaderboard 제출 제한 (연 2회)
  - 코드 공개 의무화 (재현성 보장)

### **4. 국가적 중요성: 왜 벤치마크 구축이 핵심 과제인가?**

#### **4-1. 기술 주권 확보**
- **현황**: ImageNet (미국), COCO (미국), GLUE (미국) 등 서구 중심 벤치마크
- **문제**: 한국인 뇌 데이터 없음 → 서구 벤치마크로만 평가 → 한국인 성능 15-20% 저하
- **해결**: K-Brain Benchmark → 한국형 평가 표준 → **국제 표준으로 제안** (아시아 대표)
- **효과**: 한국이 뇌 AI 평가 표준을 선도 → 국제 학회에서 benchmark challenge 주최 → 국제 위상 강화

#### **4-2. 산업 생태계 촉진**
- **현황**: 스타트업이 "우리 모델 90% 정확도" 주장해도 검증 불가 → 투자 유치 어려움
- **효과**: 표준 벤치마크 존재 → 공정한 성능 비교 → 스타트업 진입 장벽 완화
- **사례**: ImageNet 덕분에 컴퓨터 비전 스타트업 폭발적 성장 (DeepMind, Clarifai 등)
- **목표**: K-Brain Benchmark → 국내 뇌 AI 스타트업 **10-30개 창업 유도** (5년)

#### **4-3. 연구 재현성 보장**
- **현황**: 각 연구마다 다른 데이터, 다른 평가 → 결과 비교 불가, 재현율 <50%
- **효과**: 표준 벤치마크 → 객관적 검증 → 과학적 신뢰도 향상
- **사례**: ADNI 프로토콜 덕분에 치매 연구 **1,000+ 논문 발표** (Weiner et al., 2013)
- **목표**: K-Brain Benchmark → 국내외 **200+ 논문 발표** (5년)

#### **4-4. 의료기기 인허가 기준**
- **현황**: 식약처 AI 의료기기 인허가 시 성능 입증 기준 불명확 → 규제 불확실성
- **효과**: 표준 벤치마크 → **인허가 심사 기준**으로 활용 → 상용화 가속
- **목표**: K-Brain Benchmark 기반 **5개 AI 의료기기 인허가** (5년)

#### **4-5. 국제 경쟁력 및 표준화 선도**
- **현황**: 뇌 AI 국제 표준 부재 → 선점 기회
- **효과**: 한국이 선도적 구축 → 아시아 표준으로 확산 → 국제 표준 제안
- **사례**: ImageNet 논문 **10만+ 인용** (역대 최다 인용 AI 논문)
- **목표**: K-Brain Benchmark 논문 **1,000+ 인용** (5년), Nature/Science 게재

본 사업의 성공적 수행을 위해서는 대규모 뇌 영상 데이터 처리 및 거대 AI 모델 학습을 위한 강력한 컴퓨팅 인프라가 필수적입니다. 미국 DOE INCITE 프로그램의 Computational Readiness 요구사항을 참고하여, 본 사업의 계산 자원 요구량을 정량적으로 산출하였습니다.

#### **1. 컴퓨팅 자원 요구량 (TFLOPs 기반)**

**[사전 준비 단계 벤치마킹 결과]**

본 사업팀은 사전 연구를 통해 소규모 프로토타입 모델의 계산 요구량을 정량화하였습니다:

- **Baseline 모델 (100명 데이터, 1억 파라미터)**:
  - 단일 에폭 학습: 500 TFLOPs (NVIDIA A100 1대, 약 8시간)
  - 전체 학습 (100 에폭): 50 PFLOPs
  - 추론 (100명 평가): 5 TFLOPs (약 10분)

- **확장성 검증 (Strong Scaling)**:
  - 1 GPU (A100): 500 TFLOPs/에폭, 8시간
  - 2 GPUs: 520 TFLOPs/에폭, 4.2시간 (95% 효율)
  - 4 GPUs: 540 TFLOPs/에폭, 2.2시간 (91% 효율)
  - 8 GPUs: 560 TFLOPs/에폭, 1.2시간 (83% 효율)
  - **결론**: 8 GPU까지 80% 이상 병렬 효율 유지

- **확장성 검증 (Weak Scaling)**:
  - 1 GPU, 100명 데이터: 500 TFLOPs/에폭
  - 2 GPUs, 200명 데이터: 1,000 TFLOPs/에폭 (100% 선형 확장)
  - 4 GPUs, 400명 데이터: 2,000 TFLOPs/에폭 (100% 선형 확장)
  - 8 GPUs, 800명 데이터: 4,000 TFLOPs/에폭 (100% 선형 확장)
  - **결론**: 데이터 규모에 비례하여 완벽한 선형 확장성 달성

**[사업 목표 모델 계산 요구량]**

위의 벤치마킹 결과와 **미국 DOE INCITE 프로그램의 NeuroX-Fusion 프로젝트** (130B 파라미터, 1,269,000 노드시간, 152,280 PFLOPs)를 참고하여, 본 사업의 계산 요구량을 정량적으로 산출하였습니다. 계산 공식은 **Training FLOPs ≈ 6 × N(파라미터 수) × D(토큰/데이터 수)** 를 기준으로 하였습니다.
