# Psych-Raptor RAG System

이 폴더는 심리학과 교수님들의 연구 관련 검색을 위한 Psych-Raptor RAG (Retrieval-Augmented Generation) 시스템 구축을 위한 데이터 저장소입니다.

## 목적
- 심리학과 교수님들의 연구 논문 및 자료를 기반으로 한 질의응답 시스템 구축
- 연구 분야, 주요 논문, 연구 주제 등에 대한 효율적인 검색 지원

## 폴더 구조
이 폴더에는 각 교수님 별로 하위 폴더가 구성되어 있으며, 각 폴더 내에는 해당 교수님의 연구 논문(PDF) 등 Golden Reference 자료가 포함되어 있습니다.

## 사용 방법
이 데이터는 RAG 시스템의 인덱싱 과정에서 문서 소스로 활용됩니다.
