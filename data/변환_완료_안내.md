### 핵심 내용 요약

#### 기술 아키텍처
- **3-Stage Hierarchical Architecture**
  - Stage 1: Modality-specific encoders (fMRI + EEG + dMRI)
  - Stage 2: Cross-modal fusion (cross-attention)
  - Stage 3: Task-specific heads (classification, regression)
- **Model Size**: 300M parameters
- **Computing**: 10x NVIDIA A100 80GB GPUs

#### 데이터 계획
- **한국인 데이터**: 2,500명 (1,500 신규 + 1,000 기존)
- **Modalities**: fMRI + dMRI + EEG + 행동 데이터
- **Public datasets**: HCP, UK Biobank (pre-training용)

#### 성과 목표 (KPIs)
1. Cognitive classification F1 > 0.80
2. Disease prediction AUC > 0.85
3. Brain age MAE < 5 years
4. Publications: 10+ papers
5. Hospital pilots: 3 hospitals, 300+ patients
6. Open platform: 100+ downloads

#### 차별성 (vs BrainLM)
| 항목 | BrainLM | K-NeuroMind |
|------|---------|-------------|
| Modality | fMRI only | fMRI + dMRI + EEG |
| Population | Western | **Korean-specific** |
| Architecture | End-to-end | **Hierarchical 3-stage** |
| Clinical | None | **3 hospital pilots** |
| Access | Proprietary | **Fully open** |
