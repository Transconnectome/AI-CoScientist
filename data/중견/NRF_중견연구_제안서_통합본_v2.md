# 1. 연구과제의 필요성

## 1.1 연구 배경: 뇌 노화 연구의 패러다임 전환 필요성

인간의 뇌는 출생부터 노년까지 연속적인 발달-노화 궤적을 따르며, 이 과정의 개인차가 신경퇴행성 질환 발병을 결정한다. 최근 대규모 뇌영상 코호트(UK Biobank 50,000명, ABCD 12,000명)와 딥러닝의 발전으로 "뇌 연령(Brain Age)" 예측 연구가 활발하나, **두 가지 근본적 한계**가 존재한다:

### 첫 번째 한계: "나이"가 아닌 "궤적"이 필요하다

| 기존 접근 (Brain Age) | 본 연구 접근 (궤적 예측) |
|---------------------|------------------------|
| 단일 시점 예측: "이 사람의 뇌 나이는 65세" | 시간 변화 예측: "이 사람의 뇌는 연 1.5% 속도로 노화 중" |
| 스냅샷 정보 | 변화 속도/방향/가속도 |
| 개인 내 변화 포착 불가 | 개인 맞춤형 궤적 예측 |
| 정적 위험도 | 동적 개입 시점 제시 |

**핵심 통찰**: 임상적으로 actionable한 정보는 "현재 상태"가 아닌 "변화 궤적"이다.

### 두 번째 한계: 횡단면 학습의 종단 예측 실패

| 문제 | 근거 | 출처 |
|------|------|------|
| **횡단면 과소추정** | 횡단면 데이터로 학습된 모델은 실제 종단 변화를 과소추정 | PNAS 2023 |
| **회귀 평균 편향** | 어린 피험자 과대추정, 노인 과소추정 | de Lange & Cole 2020 |
| **제한된 임상 유용성** | UK Biobank n>17,000에서 최대 효과크기 partial eta^2 = 0.0059 | Cole 2020 |
| **Brain-Age Paradox** | 단순 Ridge 회귀가 복잡한 CNN/Transformer보다 임상적 민감도 더 높음 | PLOS Biology 2024 |

## 1.2 기존 연구의 한계

| 모델 | 주요 기여 | 핵심 한계 |
|------|----------|----------|
| **NeuroSTORM (2025)** | 28.65M fMRI 프레임, Mamba 아키텍처 | 횡단면 데이터만, 궤적 예측 불가 |
| **BrainLM (ICLR 2024)** | Zero-shot 추론 능력 | fMRI 단일 모달리티, 종단 검증 없음 |
| **COMICAL (2024)** | 유전체-영상 통합 | Brain Age 중심, 궤적 접근 없음 |

## 1.3 핵심 갭 (1문장)

> **"기존 Brain Age Gap 연구는 단일 시점 '나이'만 예측하며, 발달-노화 '궤적(변화 속도/방향)'을 예측하는 멀티모달 대규모 파운데이션 모델이 부재하여, 임상적으로 actionable한 조기 개입 시점을 제시하지 못한다."**

## 1.4 창의성 및 도전성

### 창의성 (Originality)

| 창의성 | 기존 | 본 연구 |
|--------|------|--------|

# 2. 연구과제의 목표 및 내용

## 2.1 연구과제의 최종 목표

> **발달-노화 궤적 예측 멀티모달 파운데이션 모델 개발**:
> 생애주기 전체(8-90세)의 뇌영상(fMRI/sMRI)-뇌파(EEG)-유전체 데이터를 모달리티별 대규모 파운데이션 모델(fMRI 100B, EEG 100B, Genomic 100B)로 사전학습하고, 경량 LLM(100M)을 의미적 융합층으로 활용하여 **발달기 뇌 성숙 궤적**과 **노화기 인지 저하 궤적**을 개인 수준에서 예측하며, 다양한 다운스트림 태스크에서 SOTA 성능을 달성하는 임상 추론 시스템을 구축한다.

## 2.2 선행연구 분석 및 차별성

| 구분 | NeuroSTORM (2025) | BrainLM (ICLR 2024) | COMICAL (2024) | **본 연구** |
|------|-------------------|---------------------|----------------|------------|
| **데이터 규모** | 28.65M 프레임, 50K+ | 6,700시간 fMRI | 40,426명 | **70K MRI + 30Kh EEG + 13K 유전체** |
| **모달리티** | fMRI 단일 | fMRI 단일 | MRI + 유전체 | **fMRI + EEG + 유전체 3-모달** |
| **모델 스케일** | 미공개 | 수억 파라미터 | 미공개 | **~300B (모달리티별 100B)** |
| **핵심 태스크** | 연령/성별/질환 | Zero-shot | 유전체-영상 연관 | **궤적 예측 (발달+노화)** |
| **종단 예측** | 횡단면 | 횡단면 | 횡단면 | **종단 궤적 예측** |
| **한국인 검증** | 없음 | 없음 | 없음 | **차병원 3K + 조선대 10K** |

## 2.3 5년 연구 로드맵 (4개 목표 구조)

```
1-2차년도: 목표 1 (모달리티별 파운데이션 모델)
    ├── fMRI Foundation Model (100B)
    ├── EEG Foundation Model (100B)
    ├── Genomic Foundation Model (100B)
    └── 융합층 LLM (100M)

2-3차년도: 목표 2 (발달 궤적 예측 - 차병원 3K)
    ├── 발달기 뇌 성숙 궤적 학습
    └── 신경발달장애 조기 예측

3-4차년도: 목표 3 (노화 궤적 예측 - 조선대 10K)
    ├── 인지 저하 궤적 학습
    └── 치매 전환 시점 예측

4-5차년도: 목표 4 (임상 추론 및 다운스트림)
    ├── 모델 경량화 (300B → 3B)
    └── 8개 다운스트림 태스크 검증
```

### 목표별 핵심 지표

| 목표 | 핵심 지표 |
|------|----------|
| **목표 1** | MAE < 2.5년, 교차모달 검색 > 80% |
| **목표 2** | 궤적 RMSE < 0.15, r > 0.5 |
| **목표 3** | 치매 전환 AUC > 0.85 |
| **목표 4** | 추론 < 30초, 다운스트림 평균 AUC > 0.85 |

## 3.3 궤적 예측 방법론

```python
# Continuous Normalizing Flow for Trajectory (pseudo-code)
class BrainTrajectoryModel:
    def forward(self, x_baseline, t_target):
        z_0 = LifeSpan_FM(x_baseline)  # 300B 인코딩
        z_t = odeint(flow, z_0, t=[0, t_target])  # 궤적 적분
        return decoder(z_t[-1])  # 미래 상태 예측
```
