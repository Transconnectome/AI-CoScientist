# Page-Unit Composition: 과학 제안서를 위한 고급 편집 가이드

> **"Each page is a complete story. Each spread is a chapter."**
>
> 본 가이드는 The Economist, Nature, Harvard Business Review의 편집 원칙을 과학 제안서에 적용한 것입니다.

---

## I. 핵심 철학: 페이지 단위 완결성 (Page-Unit Completeness)

### 1.1 왜 페이지 단위인가?

```
┌─────────────────────────────────────────────────────────────┐
│  심사자의 현실                                                │
│  ─────────────────────────────────────────────────────────  │
│  - 1인당 10-20개 제안서 평가                                  │
│  - 두 쪽 모아찍기로 인쇄 (A4 → A3 축소)                       │
│  - 첫 1-2페이지로 점수 방향 결정                              │
│  - 특정 페이지만 다시 펼쳐보며 점수 확정                       │
│                                                              │
│  → 어느 페이지를 펼쳐도 그 페이지만으로 핵심을 파악 가능해야   │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 Page-Unit의 3가지 원칙

| 원칙 | 설명 | 적용 |
|:---:|:-----|:-----|
| **Semantic Closure** | 각 페이지가 하나의 완결된 의미 단위 | 문장/문단이 페이지를 넘어가지 않음 |
| **Visual Self-Sufficiency** | 그림+텍스트가 그 페이지 안에서 완결 | Figure와 설명이 같은 페이지에 |
| **Cognitive Load Balance** | 한 페이지에서 전달하는 정보량 최적화 | 1페이지 = 1핵심 메시지 |

## II. 10페이지 제안서의 Page-Unit 설계

### 2.1 페이지별 역할 정의 (NRF 핵심연구 기준)

```
┌─────────────────────────────────────────────────────────────┐
│  PAGE 1: THE HOOK (문제 정의)                                 │
│  ─────────────────────────────────────────────────────────  │
│  - 핵심 문제 1문장                                            │
│  - 왜 지금, 왜 이 연구가 필요한가                             │
│  - Fig 1: 문제-갭-가설 인포그래픽 (반페이지)                  │
│  - 이 페이지만 읽어도 연구의 필요성 파악 가능                  │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  PAGE 2: THE GAP (선행연구와 차별성)                          │
│  ─────────────────────────────────────────────────────────  │
│  - 기존 연구의 한계 (표 1개)                                  │
│  - 본 연구의 차별성 2층 구조                                  │
│  - 핵심 가설 1문장 (박스 강조)                                │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  PAGE 3-4: THE AIMS (연구 목표)                               │
│  ─────────────────────────────────────────────────────────  │
│  - 각 Aim이 1페이지 또는 반페이지 단위                        │
│  - Fig 2: 전체 연구 파이프라인 (Page 3 상단)                  │
│  - 각 Aim: 목표 + 방법 + 성공기준이 한 단위                   │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  PAGE 5-7: THE METHOD (추진전략)                              │
│  ─────────────────────────────────────────────────────────  │
│  - 각 방법론 모듈이 페이지 단위로 완결                        │
│  - Fig 3: Aim별 실험 흐름도                                   │
│  - 데이터, 분석, 검증이 각각 독립 페이지                      │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  PAGE 8: THE CAPABILITY (연구 수행역량)                       │
│  ─────────────────────────────────────────────────────────  │
│  - 선행연구 → 본 과제 연결이 한 페이지에서 완결               │
│  - 연구 진화 표 (신진→중견)                                   │
│  - 인프라/네트워크 bullet points                              │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  PAGE 9: THE TIMELINE (로드맵)                                │
│  ─────────────────────────────────────────────────────────  │
│  - Fig 4: Gantt chart + 마일스톤                              │
│  - Go/No-Go 기준 표                                           │
│  - 리스크 및 대안 (같은 페이지)                               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  PAGE 10: THE IMPACT (기대효과)                               │
│  ─────────────────────────────────────────────────────────  │
│  - 학문적/기술적/사회적 기여                                  │
│  - 후속 연구 연계                                             │
│  - 마지막 문장 = 전체 제안서의 결론                           │
└─────────────────────────────────────────────────────────────┘
```

## III. 실전 편집 테크닉

### 3.1 문장/문단 경계 관리

**원칙: No Orphans, No Widows**

```
❌ 잘못된 예 (Orphan):
   ... 본 연구에서는 이러한 문제를 해결하기 위해
   ─────────────────── [페이지 경계] ───────────────────
   UCCT 프레임워크를 적용한다.

✅ 올바른 예:
   ... 본 연구에서는 이러한 문제를 해결하기 위해 UCCT 프레임워크를 적용한다.
   ─────────────────── [페이지 경계] ───────────────────
   [새로운 섹션 시작]
```

**실행 방법:**
1. 각 페이지의 마지막 줄이 문단의 끝인지 확인
2. 문단이 페이지를 넘어가면 → 문장을 줄이거나 / 이전 페이지 여백 조절
3. 표나 그림이 잘리면 → 크기 조절 또는 다음 페이지로 이동

### 3.2 Figure-Text 동기화

**원칙: 그림과 설명이 같은 시야(視野)에**

```
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│  ┌─────────────────────────────────────┐                    │
│  │                                      │                    │
│  │         Figure 1                     │  ← 상단 1/2       │
│  │    (문제-갭-가설 인포그래픽)          │                    │
│  │                                      │                    │
│  └─────────────────────────────────────┘                    │
│                                                              │
│  Figure 1은 본 연구의 핵심 문제와 해결 접근을 보여준다.       │
│  기존 연구(좌측)는 ... 한계가 있으며, 본 연구(우측)는 ...    │  ← 하단 1/2
│  차별화된 접근을 제안한다. 핵심 가설은 다음과 같다:           │
│                                                              │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  "멀티모달 신호가 의미론적 앵커로 작용하여..."         │   │  ← 박스 강조
│  └─────────────────────────────────────────────────────┘   │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 시각적 리듬 (Visual Rhythm)

**원칙: 밀도의 교차**

```
Page 1: ████████░░ (80% 밀도 - 문제 정의, 긴장감)
Page 2: ██████░░░░ (60% 밀도 - 여백 있는 표)
Page 3: ████████░░ (80% 밀도 - Aims)
Page 4: ██████████ (100% 밀도 - 핵심 방법론)
Page 5: ██████░░░░ (60% 밀도 - 그림 중심)
Page 6: ████████░░ (80% 밀도 - 방법론 상세)
Page 7: ██████░░░░ (60% 밀도 - 데이터/검증)
Page 8: ████████░░ (80% 밀도 - 연구역량)
Page 9: ██████░░░░ (60% 밀도 - Gantt 중심)
Page 10: ████░░░░░░ (40% 밀도 - 여백, 마무리)
```

## IV. 모듈러 그리드 시스템

### 4.1 6열 모듈러 그리드

```
┌────┬────┬────┬────┬────┬────┐
│ 1  │ 2  │ 3  │ 4  │ 5  │ 6  │  ← 6 columns
├────┴────┴────┴────┴────┴────┤
│         전체 너비 텍스트       │  ← 6열 사용
├────────────────┬────────────┤
│    본문 (4열)   │  사이드(2열) │  ← 4:2 분할
├────────┬───────┴────────────┤
│ 그림(3) │      본문 (3열)      │  ← 3:3 분할
└────────┴────────────────────┘
```

### 4.2 표준 레이아웃 패턴

**Pattern A: 전체 너비 텍스트**
- 사용: 서론, 결론, 핵심 논증
- 장점: 연속적 읽기에 적합

**Pattern B: 텍스트 + 사이드 박스**
- 사용: 핵심 수식, 정의, 강조 사항
- 장점: 핵심 정보 빠른 파악

**Pattern C: 그림 + 텍스트 병렬**
- 사용: 방법론 설명, 결과 해석
- 장점: 시각-텍스트 동시 참조

**Pattern D: 전체 너비 그림**
- 사용: 파이프라인, Gantt chart
- 장점: 복잡한 정보의 시각적 전달

## V. 타이포그래피 계층

### 5.1 4단계 계층 시스템

| 레벨 | 요소 | 크기 | 스타일 | 예시 |
|:---:|:-----|:---:|:------|:-----|
| H1 | 섹션 제목 | 14pt | Bold | **1. 연구의 필요성** |
| H2 | 소제목 | 12pt | Bold | **1.1 핵심 문제** |
| H3 | 항목 제목 | 11pt | Bold Italic | ***선행연구 1*** |
| Body | 본문 | 10-11pt | Regular | 일반 텍스트 |

### 5.2 강조 시스템

```
┌─────────────────────────────────────────────────────────────┐
│  [박스 강조] 핵심 가설이나 1문장 요약                         │
│  ─────────────────────────────────────────────────────────  │
│  "본 연구의 핵심 가설은 ... 이다."                           │
└─────────────────────────────────────────────────────────────┘

**굵은 글씨**: 핵심 키워드, 첫 번째 언급 용어

*이탤릭*: 논문 제목, 외래어, 강조

`코드 스타일`: 기술 용어, 모델명, 약어
```

## VI. 실전 체크리스트

### 6.1 페이지별 자가 검토

각 페이지에서 다음을 확인:

- [ ] **이 페이지만 읽어도** 핵심 메시지가 전달되는가?
- [ ] 문장/문단이 페이지 경계에서 **끊기지 않는가**?
- [ ] 그림과 그 설명이 **같은 페이지**에 있는가?
- [ ] **한 가지 핵심 메시지**만 전달하고 있는가?
- [ ] 이전/다음 페이지와 **밀도의 변화**가 있는가?

### 6.2 전체 문서 검토

- [ ] 10페이지가 **10개의 완결된 스토리**인가?
- [ ] 어느 페이지를 펼쳐도 **맥락 파악이 가능**한가?
- [ ] Figure 4개가 **적절히 분산**되어 있는가?
- [ ] **시각적 리듬**(밀도 변화)이 있는가?
- [ ] 마지막 페이지가 **깔끔하게 마무리**되는가?

## VII. 적용 예시: 연구수행역량 섹션

### Before (기존 작성)
```
[Page 8 상단]
...선행연구 3의 마지막 문장이 여기서 끝나고
───────────────────────────────────────────
[Page 9 상단]
선행연구 4가 새로 시작됨 (맥락 단절)
```

### After (Page-Unit 적용)
```
[Page 8: 연구수행역량 - 완결된 1페이지]
┌─────────────────────────────────────────────────────────────┐
│  ## 4. 연구자의 연구 수행역량                                 │
│                                                              │
│  ### 연구책임자 역량 (3줄)                                    │
│                                                              │
│  ### 선행연구와 본 과제 연결                                  │
│  ┌───────────────────────────────────────────────────────┐ │
│  │ 선행연구        → 발견/임팩트    → 본 과제 기여         │ │
│  ├───────────────────────────────────────────────────────┤ │
│  │ 유전-뇌회로     → RDoC 근거     → 통합 추론 기반       │ │
│  │ 발달적 기원     → 세대간 전이   → 궤적 예측 모델       │ │
│  │ 환경-뇌 상호작용 → 언론 보도    → 다중모달 해석        │ │
│  │ AI 예측 시스템  → SwiFT 개발   → 파운데이션 모델      │ │
│  └───────────────────────────────────────────────────────┘ │
│                                                              │
│  ### 연구 프로그램 진화 (표)                                  │
│  | 차원 | 신진(2021) | 중견(2026) |                          │
│  | ... | ...        | ...        |                          │
│                                                              │
│  ### 인프라 (bullet 3개)                                      │
│  - 데이터: ...                                               │
│  - 컴퓨팅: ...                                               │
│  - 협력: ...                                                 │
│                                                              │
│  [페이지 끝 - 다음 페이지는 새로운 섹션 시작]                  │
└─────────────────────────────────────────────────────────────┘
```

## VIII. 도구 및 워크플로

### 8.1 권장 도구

| 단계 | 도구 | 용도 |
|:---:|:-----|:-----|
| 초안 | Markdown | 구조 설계, 빠른 편집 |
| 레이아웃 | MS Word / HWP | 페이지 경계 확인 |
| 그림 | PowerPoint / Figma | 인포그래픽 제작 |
| 검토 | PDF 출력 | 실제 인쇄 상태 확인 |

### 8.2 편집 워크플로

```
1. 구조 설계 (Markdown)
   - 10페이지 = 10개 섹션 정의
   - 각 페이지의 핵심 메시지 1문장

2. 콘텐츠 작성 (Markdown)
   - 페이지별 분량 가이드라인 준수
   - 그림 위치 placeholder 표시

3. 레이아웃 배치 (Word/HWP)
   - 모듈러 그리드 적용
   - 페이지 경계 조정

4. 시각적 검토 (PDF)
   - 두 쪽 모아보기로 인쇄
   - 각 페이지 완결성 확인
   - 시각적 리듬 확인

5. 최종 조정
   - Orphan/Widow 제거
   - 여백 미세 조정
```
