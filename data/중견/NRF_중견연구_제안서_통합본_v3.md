# 1. 연구과제의 필요성

## 1.1 연구 배경: 뇌 노화 연구의 패러다임 전환 필요성

인간의 뇌는 출생부터 노년까지 연속적인 발달-노화 궤적을 따르며, 이 과정의 개인차가 신경퇴행성 질환 발병을 결정한다. 최근 대규모 뇌영상 코호트(UK Biobank 50,000명, ABCD 12,000명)와 딥러닝의 발전으로 "뇌 연령(Brain Age)" 예측 연구가 활발하나, **두 가지 근본적 한계**가 존재한다:

### 첫 번째 한계: "나이"가 아닌 "궤적"이 필요하다

| 기존 접근 (Brain Age) | 본 연구 접근 (궤적 예측) |
|---------------------|------------------------|
| 단일 시점 예측: "이 사람의 뇌 나이는 65세" | 시간 변화 예측: "이 사람의 뇌는 연 1.5% 속도로 노화 중" |
| 스냅샷 정보 | 변화 속도/방향/가속도 |
| 개인 내 변화 포착 불가 | 개인 맞춤형 궤적 예측 |
| 정적 위험도 | 동적 개입 시점 제시 |

**핵심 통찰**: 임상적으로 actionable한 정보는 "현재 상태"가 아닌 "변화 궤적"이다. 이는 최근 신경과학 분야에서 주목받는 Neurospectrum Framework (2024)의 "잠재 궤적(latent trajectory)" 개념과 맥을 같이한다.

### 두 번째 한계: 횡단면 학습의 종단 예측 실패

| 문제 | 근거 | 출처 |
|------|------|------|
| **횡단면 과소추정** | 횡단면 데이터로 학습된 모델은 실제 종단 변화를 과소추정 | PNAS 2023 |
| **회귀 평균 편향** | 어린 피험자 과대추정, 노인 과소추정 | de Lange & Cole 2020 |
| **제한된 임상 유용성** | UK Biobank n>17,000에서 최대 효과크기 partial eta^2 = 0.0059 | Cole 2020 |
| **Brain-Age Paradox** | 단순 Ridge 회귀가 복잡한 CNN/Transformer보다 임상적 민감도 더 높음 | PLOS Biology 2024 |

## 1.2 기존 연구의 한계

| 모델 | 주요 기여 | 핵심 한계 |
|------|----------|----------|
| **NeuroSTORM (2025)** | 28.65M fMRI 프레임, Mamba 아키텍처 | 횡단면 데이터만, 궤적 예측 불가 |
| **BrainLM (ICLR 2024)** | Zero-shot 추론, **3-8B 파라미터** | fMRI 단일 모달리티, 종단 검증 없음 |
| **COMICAL (2024)** | 유전체-영상 통합 | Brain Age 중심, 궤적 접근 없음 |
| **Neurospectrum (2024)** | 궤적 기반 바이오마커 | 소규모 데이터, 멀티모달 미지원 |

**현재 최대 규모 뇌 FM**: BrainLM (3-8B 파라미터). 본 연구는 이를 **6-15배 초과**하는 규모 제안.

## 1.3 핵심 갭 (1문장)

> **"기존 Brain Age Gap 연구는 단일 시점 '나이'만 예측하며, 발달-노화 '궤적(변화 속도/방향)'을 예측하는 멀티모달 대규모 파운데이션 모델이 부재하여, 임상적으로 actionable한 조기 개입 시점을 제시하지 못한다."**

## 3.3 궤적 예측 방법론: Continuous Normalizing Flow

본 연구는 Neurospectrum Framework (2024)에서 제시된 잠재 궤적(latent trajectory) 개념을 대규모 파운데이션 모델에 적용한다. Neural ODE 기반 Continuous Normalizing Flow를 통해 개인별 뇌 변화 궤적을 연속 시간 함수로 모델링한다.

```python
# Continuous Normalizing Flow for Brain Trajectory (pseudo-code)
class BrainTrajectoryModel:
    def __init__(self):
        self.encoder = LifeSpan_FM()  # 50B 멀티모달 인코더
        self.flow = NeuralODE(hidden_dim=2048)
        self.decoder = TrajectoryDecoder()

    def forward(self, x_baseline, t_target):
        z_0 = self.encoder(x_baseline)  # 50B 인코딩
        z_t = odeint(self.flow, z_0, t=[0, t_target])  # 궤적 적분
        return self.decoder(z_t[-1])  # 미래 상태 예측

    def predict_trajectory(self, x_baseline, time_points):
        """전체 궤적 예측: 속도, 방향, 가속도"""
        z_0 = self.encoder(x_baseline)
        trajectory = odeint(self.flow, z_0, t=time_points)
        velocity = torch.diff(trajectory, dim=0)  # 변화 속도
        acceleration = torch.diff(velocity, dim=0)  # 가속도
        return trajectory, velocity, acceleration
```
