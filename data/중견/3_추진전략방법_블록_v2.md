### 1.2 fMRI Foundation Model (100B): 4D Swin Transformer

#### 아키텍처 명세

```
Input: 4D fMRI volume (91x109x91 x T timepoints)
       T = 200-1200 (가변 시퀀스)

Patch Embedding:
- 3D spatial patches: 4x4x4 voxels → 1024-dim tokens
- Temporal patches: 8 timepoints → temporal tokens
- Total patches: ~50,000 per subject

4D Swin Transformer Blocks (x48 layers):
- Window-based Multi-head Self-Attention (W-MSA)
- Shifted Window MSA (SW-MSA)
- 3D spatial shift + temporal shift
- Hidden dim: 2048 → 4096 (progressive)

Self-Supervised Pretraining:
- Masked Autoencoder (MAE): 75% random masking
- Prediction target: raw voxel intensities

Model Configuration:
- Layers: 48
- Heads: 32
- Hidden: 4096
- FFN: 16384
- Parameters: ~100B
```

#### 학습 전략

| 단계 | 파라미터 | 데이터 | GPU | 기간 |
|------|----------|--------|-----|------|
| Stage 1 | 1B | UK Biobank 10K | A100x8 | 2주 |
| Stage 2 | 10B | UK Biobank 30K | A100x64 | 4주 |
| Stage 3 | 50B | 전체 50K | A100x256 | 8주 |
| Stage 4 | 100B | 전체 70K + TUEG | A100x512 | 12주 |

**컴퓨팅 전략**:
- Gradient Checkpointing: 메모리 50% 절감
- Mixed Precision (BF16): 속도 2x
- FSDP (Fully Sharded Data Parallel): 512 GPU 분산
- FlashAttention-2: 어텐션 2x 가속

### 1.3 EEG Foundation Model (100B): DIVER-XL

#### 아키텍처 명세 (DIVER 확장)

```
Input: EEG (C channels x T samples, 200Hz)
       C = 19-128 (가변 채널), T = 200-6000 (1-30초)

Channel-Equivariant Tokenization:
- DIVER 채널 토큰화: 순열 등변성 보장
- Temporal patching: 100 samples (0.5초) → 1024-dim

DIVER-XL Transformer (x48 layers):
- Rotary Position Embedding (RoPE)
- Binary Attention Bias for channel relations
- Channel permutation equivariance
- Hidden dim: 4096

Self-Supervised Pretraining:
- Time-Channel Masked Modeling
- 50% time masking + 30% channel masking
- Contrastive learning across channels

Model Configuration:
- Layers: 48
- Heads: 32
- Hidden: 4096
- Parameters: ~100B
```

#### 핵심 혁신: 채널 순열 등변성

```
기존 EEG 모델 문제:
- 채널 순서에 민감 (19ch vs 128ch 호환 불가)
- 전극 배치 변동에 취약

DIVER-XL 해결책:
- f(Pσ(X)) = Pσ(f(X)) for any permutation σ
- 임의의 전극 구성에서 일관된 표현 학습
- 19채널 저밀도 ~ 128채널 고밀도 연속 스펙트럼 지원
```

### 1.4 Genomic Foundation Model (100B): PRS Transformer

#### 아키텍처 명세

```
Input: Polygenic Risk Scores (PRS) + SNP embeddings
       - 50+ PRS traits (AD, PD, intelligence, etc.)
       - Top 100K SNPs from GWAS

PRS Transformer:
- SNP Embedding: 100K variants → 512-dim
- Trait Embedding: 50 PRS → 1024-dim
- Cross-attention: SNP ↔ Trait
- Self-attention across traits

Pretraining:
- Masked trait prediction
- Contrastive learning (같은 개인의 다른 모달리티)

Output: 2048-dim genomic representation
```

### 1.5 LLM Fusion Layer (100M): 의미적 브릿지

#### 아키텍처

```
3-Modal Fusion via Lightweight LLM:

Input Representations:
- z_fmri: 2048-dim (from fMRI FM)
- z_eeg: 2048-dim (from EEG FM)
- z_gen: 2048-dim (from Genomic FM)

Cross-Modal Attention (100M params):
- Query: z_fmri
- Key/Value: [z_eeg, z_gen]
- Multi-head cross-attention (16 heads)
- Feed-forward: 4096 → 2048

Semantic Alignment:
- Shared latent space projection
- Contrastive loss across modalities
- Language supervision (optional)

Output: z_unified (2048-dim integrated representation)
```

**설계 근거**:
- 대규모 융합층(수십B) 대신 경량 LLM(100M) 사용
- 각 모달리티 인코더가 충분히 크므로 융합은 정렬에 집중
- 추론 시 모달리티 조합 유연성 확보 (fMRI만, EEG만, 전체)

## 목표 2: 발달 궤적 예측 방법론

### 2.1 궤적 모델링: Continuous Normalizing Flow (CNF)

#### 이론적 기반

```
기존 Brain Age (단일 시점):
- y = f(x) + ε
- x: 뇌영상, y: 예측 연령 (스칼라)
- 한계: 개인 내 변화 무시

궤적 예측 (시간에 따른 변화):
- y(t) = f(x(t), t) + ε(t)
- 목표: dy/dt (변화 속도), d²y/dt² (가속도)

Continuous Normalizing Flow:
- dz/dt = f_θ(z, t)
- z(0) ~ p(z_0 | x_baseline)
- z(T) = future brain state prediction
```

#### 구현

```python
# CNF for Trajectory Prediction (pseudo-code)
class BrainTrajectoryModel:
    def __init__(self):
        self.encoder = LifeSpanFM(300B)  # Frozen
        self.flow = NeuralODE(hidden=2048)
        self.decoder = MLPHead(2048 -> brain_features)

    def forward(self, x_baseline, t_target):
        # 1. Encode baseline
        z_0 = self.encoder(x_baseline)

        # 2. Integrate trajectory
        z_t = odeint(self.flow, z_0, t=[0, t_target])

        # 3. Decode future state
        y_pred = self.decoder(z_t[-1])
        return y_pred

    def predict_trajectory(self, x_baseline, t_points):
        # Full trajectory prediction
        z_0 = self.encoder(x_baseline)
        z_traj = odeint(self.flow, z_0, t=t_points)
        return [self.decoder(z) for z in z_traj]
```

|--------|------|------|----------|

## 목표 3: 노화/치매 궤적 예측 방법론

### 3.1 치매 전환 예측 모델

```
입력:
- x_t0: Baseline MRI + EEG + Genomic
- t: 시간 (예측 시점)

출력:
- P(AD | x_t0, t): t 시점까지 치매 전환 확률
- y_trajectory: 인지 저하 궤적

모델:
- Cox Proportional Hazards with Neural Features
- h(t|x) = h_0(t) * exp(β * LifeSpan-FM(x))

해석:
- Hazard Ratio > 2.0: 고위험군
- 개인화된 전환 시점 예측
```

### 3.2 조선대 종단 데이터 활용 전략

```
데이터 구조:
- N = 10,000명 (50-90세)
- 진단 분포: CN 70%, MCI 20%, AD 10%
- 추적 기간: 5-10년 (평균 6년)
- 총 데이터포인트: ~40,000

학습 전략:
1. LifeSpan-FM 임베딩 (사전학습 모델 활용)
2. MCI → AD 전환 예측: Survival Analysis
3. 인지 저하 궤적: Mixed-Effects CNF
4. 한국인 특이적 보정: Domain Adaptation
```

### 3.3 한국인 도메인 적응

```
문제: 서양인 중심 사전학습 → 한국인 적용 시 성능 저하
- 인종별 뇌 구조 차이
- 생활습관/환경 요인 차이
- 질환 유병률 차이

해결: Parameter-Efficient Fine-Tuning (PEFT)
- LoRA (Low-Rank Adaptation): rank=32
- 전체 300B 중 0.1% (~300M)만 학습
- 한국인 데이터 13,000명으로 적응

검증:
- 서양인 모델 vs 한국인 적응 모델
- 목표: 성능 격차 < 5%
```

### 4.2 모델 경량화 파이프라인

```
Full Model: 300B (fMRI 100B + EEG 100B + Genomic 100B + LLM 100M)
                           ↓
Knowledge Distillation:
- Teacher: 300B full model
- Student: 3B (각 모달리티 1B)
- Distillation: Feature + Logit matching
                           ↓
Quantization:
- INT8 quantization (TensorRT)
- 3B → 0.8B effective
                           ↓
Deployment Model: ~1B INT8 (추론용)

추론 성능:
- Full 300B: ~300초/case (연구용)
- Distilled 3B: ~30초/case (임상용)
- Quantized 1B: ~10초/case (스크리닝용)
```

| 궤적 예측 정확도 미달 | 중간 | 횡단면 + 종단 하이브리드 |
| 추론 지연 초과 | 낮음 | 추가 경량화, 모달리티 선택 |
