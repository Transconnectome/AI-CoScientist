## 1) 연구과제의 최종 목표

> **생애주기 전체(8-90세)를 아우르는 뇌영상-뇌파-유전체 멀티모달 파운데이션 모델을 개발하고, 발달기 뇌 구조/기능/전기생리 성숙 패턴으로부터 노화 가속 위험을 예측하며, 임상 현장에서 활용 가능한 실시간 멀티모달 추론 시스템을 구축하여 한국인 코호트에서 검증한다.**

## 2) 연구과제의 내용

### 선행연구 분석 및 차별성

| 구분 | 기존 뇌영상 모델 | 채널등변 뇌파 모델 | Cole et al. | **본 연구** |
|------|-----------------|-------------------|-------------|------------|
| **연령 범위** | 성인 (45-80세) | 전 연령 | 성인 | **8-90세 전 생애주기** |
| **모달리티** | 구조 자기공명영상 | 뇌파 단일 | 구조 자기공명영상 | **구조/기능 자기공명영상+뇌파+유전체** |
| **학습 방식** | 마스크 자기인코더 | 채널등변 블록 | 회귀 | **시공간 트랜스포머 + 대조학습** |
| **뇌파 통합** | 미포함 | 채널순열등변 | 미포함 | **채널등변 뇌파 인코더 통합** |
| **발달 패턴** | 미포함 | 미포함 | 미포함 | **발달-노화 연속체 모델링** |
| **추론 시스템** | 없음 | 없음 | 없음 | **실시간 멀티모달 서비스 + 임상지원** |
| **한국인 검증** | 없음 | 없음 | 없음 | **한국인 10,000명 검증** |

### 2-Layer 차별성 구조

**Layer 1 (개념적 차별성): 발달-노화 연속체 가설 + 임상 추론**
> "뇌 노화는 발달의 역순이 아니라, 발달 과정에서 결정된 개인별 궤적의 연장이며, 이를 임상에서 실시간으로 활용할 수 있어야 한다."
> - 기존: 연구용 모델, 오프라인 분석
> - 본 연구: End-to-end 파운데이션 모델 + 실시간 임상 추론 시스템

**Layer 2 (실행적 차별성): 멀티모달 파운데이션 모델 + 추론 파이프라인**
> - **시공간 트랜스포머**: 시공간 뇌 구조 변화 동시 학습
> - **채널등변 뇌파 인코더**: 채널 순열 등변성 기반 뇌파 파운데이션 모델 (Temple 뇌파 코퍼스 30,000시간 사전학습)
> - **교차모달 대조학습**: 뇌영상-뇌파-유전체 3-모달 공동 임베딩 공간 구축
> - **효율적 미세조정**: 한국인 코호트 효율적 도메인 적응
> - **추론 최적화**: 모델 경량화 및 가속, <30초 멀티모달 추론

## 5년 연구 로드맵 (4개 목표 구조)

```
1-2차년도: 목표 1 (파운데이션 모델)
    ├── 데이터 통합 (70,000+ 뇌영상)
    └── 시공간 트랜스포머 사전학습

2-3차년도: 목표 2 (멀티모달 융합)
    ├── 뇌영상-뇌파-유전체 교차모달 학습
    └── 발달-노화 바이오마커 도출

3-4차년도: 목표 3 (임상 검증)
    ├── 뇌 연령 격차 모델 완성
    └── 한국인 코호트 검증

4-5차년도: 목표 4 (추론 및 배포)
    ├── 실시간 추론 시스템 개발
    └── 임상 파일럿 및 의사결정지원 연동
```

## 목표 1: 생애주기 뇌 파운데이션 모델 개발 (1-2차년도)

**목표**: 70,000+ 뇌영상으로 사전학습된 생애주기 뇌 파운데이션 모델 구축

**핵심 질문**:
> "발달기부터 노화기까지의 뇌 구조 변화를 하나의 통합 표현 공간에서 학습할 수 있는가?"

**주요 내용**:

| 세부 과제 | 설명 | 산출물 |
|----------|------|--------|
| 1.1 데이터 통합 | UK Biobank(50,000) + ABCD(12,000) + HCP(2,500) 전처리 | 통합 데이터셋 |
| 1.2 시공간 인코더 | 시공간 자기지도학습 (마스크 자기인코더) | 사전학습 모델 |
| 1.3 연령 연속 표현 | 연속 정규화 흐름으로 연령 임베딩 | 연령인식 표현 |
| 1.4 모델 스케일링 | 10억 → 50억 파라미터 스케일업 | 대규모 파운데이션 모델 |

**핵심 지표**:
- 사전학습 손실 수렴
- 선형 탐침 연령 예측 평균절대오차 < 3.0년
- 제로샷 전이 성능 > 기존 최고 성능

## 목표 2: 멀티모달 융합 및 바이오마커 발견 (2-3차년도)

**목표**: 뇌영상-뇌파-유전체 멀티모달 융합을 통한 생애주기 바이오마커 도출

**핵심 질문**:
> "발달기 뇌 구조/기능/전기생리 성숙 패턴을 결정하는 유전적 요인이 노화 가속과 어떤 관계가 있는가?"

**주요 내용**:

| 세부 과제 | 설명 | 산출물 |
|----------|------|--------|
| 2.1 유전체 통합 | 전장유전체연관분석 기반 다유전자위험점수 계산 및 임베딩 | 유전체 임베딩 모듈 |
| 2.2 채널등변 뇌파 인코더 | 채널순열등변 뇌파 파운데이션 모델 (Temple 코퍼스 사전학습 활용) | 뇌파 임베딩 모듈 |
| 2.3 3-모달 융합 | 뇌영상-뇌파-유전체 교차모달 대조학습 | 공동 표현 공간 |
| 2.4 발달-노화 상관분석 | ABCD 발달 패턴 (자기공명영상+뇌파) → UK Biobank 노화 예측 전이 | 상관 바이오마커 |
| 2.5 멀티모달 추론 모듈 | 입력 모달리티 유연 처리 (자기공명영상/뇌파/유전체 조합) | 유연 추론 |

**뇌파 바이오마커**:
- 주파수 대역 파워: 델타, 세타, 알파, 베타, 감마
- 발달 지표: N170 지연, P300 진폭, 오류관련 음성파 패턴
- 노화 지표: 알파 피크 주파수 감소, 세타/베타 비율 변화
- 연결성: 위상동기화값, 일관성

**핵심 지표**:
- 발달-노화 상관계수 r > 0.3
- 유전적 설명력 (유전율) h² > 0.4
- 교차모달 검색 > 75%
- 뇌파-자기공명영상 상관 r > 0.25

## 목표 3: 임상 검증 및 한국인 적응 (3-4차년도)

**목표**: 뇌 연령 격차 예측 모델 완성 및 한국인 코호트 검증

**핵심 질문**:
> "서양인 기반 모델이 한국인에게 일반화되는가? 노화 가속 예측이 임상적으로 유의미한가?"

**주요 내용**:

| 세부 과제 | 설명 | 산출물 |
|----------|------|--------|
| 3.1 뇌 연령 격차 모델 | 미세조정된 연령 예측 + 격차 계산 | 예측 모델 |
| 3.2 한국인 도메인 적응 | 한국인유전체역학조사 데이터로 효율적 미세조정 | 한국인 모델 |
| 3.3 임상 상관 검증 | 인지기능, 치매 위험도와 뇌 연령 격차 상관 | 검증 논문 |
| 3.4 다민족 일반화 | 아시아 코호트 확장 검증 준비 | 일반화 프로토콜 |

**핵심 지표**:
- 연령 예측 평균절대오차 < 2.5년
- 한국인 일반화 성능 저하 < 10%
- 인지저하 예측 곡선하면적 > 0.75

## 목표 4: 추론 시스템 및 임상 배포 (4-5차년도)

**목표**: 실시간 뇌 연령 추론 서비스 및 임상 의사결정 지원 시스템 개발

**핵심 질문**:
> "파운데이션 모델을 임상 현장에서 실시간으로 활용할 수 있는 시스템을 어떻게 구축할 것인가?"

**주요 내용**:

| 세부 과제 | 설명 | 산출물 |
|----------|------|--------|
| 4.1 모델 최적화 | 모델 경량화 및 가속 변환, 양자화 (8비트 정수) | 경량화 모델 |
| 4.2 추론 서비스 개발 | 웹 서비스 인터페이스 | 뇌 연령 추론 서비스 |
| 4.3 임상시스템 통합 | 의료영상저장전송/전자의무기록 연동, 의료정보교환표준 준수 | 임상 통합 모듈 |
| 4.4 파일럿 운영 | 협력 병원 1,000명 대상 실증 | 파일럿 결과 |

**추론 시스템 아키텍처**:

```
┌─────────────────────────────────────────────────────────────┐
│              멀티모달 추론 시스템                             │
├─────────────────────────────────────────────────────────────┤
│  입력 계층                                                   │
│  ├── 의료영상 파서 (구조/기능 자기공명영상)                   │
│  ├── 뇌파 로더 (200Hz 리샘플링)                             │
│  ├── 유전체 로더 (다유전자위험점수 변환)                      │
│  └── 전처리 파이프라인                                       │
├─────────────────────────────────────────────────────────────┤
│  모달리티 인코더                                             │
│  ├── 시공간 트랜스포머 (자기공명영상)                         │
│  ├── 채널등변 뇌파 인코더 (회전위치임베딩)                    │
│  └── 유전체 트랜스포머 (유전체 임베딩)                        │
├─────────────────────────────────────────────────────────────┤
│  추론 엔진                                                   │
│  ├── 교차모달 어텐션 (유연 3-모달 융합)                       │
│  ├── 누락 모달리티 처리기 (토큰 기반)                         │
│  └── 뇌 연령 예측기 (최적화 모델)                            │
├─────────────────────────────────────────────────────────────┤
│  출력 계층                                                   │
│  ├── 뇌 연령 보고서 + 뇌파 바이오마커 요약                    │
│  ├── 위험도 대시보드 (구조/기능/전기생리 통합)                │
│  └── 의료정보교환표준 리소스 (전자의무기록 통합)              │
└─────────────────────────────────────────────────────────────┘
```

**핵심 지표**:
- 추론 지연시간 < 30초/영상
- 처리량 > 100 영상/일
- 시스템 가용성 > 99.5%
- 임상의 만족도 > 4.0/5.0

**멀티모달 추론 시나리오**:

| 입력 조합 | 사용 사례 | 예측 정확도 |
|----------|----------|------------|
| 구조 자기공명영상 단독 | 일반 건강검진 | 평균절대오차 ~3.0년 |
| 뇌파 단독 | 저비용 스크리닝 | 평균절대오차 ~3.5년 |
| 구조 + 기능 자기공명영상 | 신경과 정밀검사 | 평균절대오차 ~2.5년 |
| 구조 자기공명영상 + 뇌파 | 구조-기능 통합 검진 | 평균절대오차 ~2.3년 |
| 구조 자기공명영상 + 유전체 | 유전체 연계 검진 | 평균절대오차 ~2.3년 |
| 구조/기능 자기공명영상 + 뇌파 | 신경과 종합검사 | 평균절대오차 ~2.0년 |
| 구조/기능 자기공명영상 + 유전체 | 연구/고위험군 | 평균절대오차 ~2.0년 |
| 구조/기능 자기공명영상 + 뇌파 + 유전체 | 전체 멀티모달 (연구용) | 평균절대오차 ~1.8년 |
