# 1. 연구과제의 필요성

## 1.1 연구 배경: 뇌 노화 연구의 패러다임 전환 필요성

인간의 뇌는 출생부터 노년까지 연속적인 발달-노화 궤적을 따르며, 이 과정의 개인차가 신경퇴행성 질환 발병을 결정한다. 최근 대규모 뇌영상 코호트(UK Biobank 50,000명, ABCD 12,000명)와 딥러닝의 발전으로 "뇌 연령(Brain Age)" 예측 연구가 활발하나, **두 가지 근본적 한계**가 존재한다:

### 첫 번째 한계: "나이"가 아닌 "궤적"이 필요하다

| 기존 접근 (Brain Age) | 본 연구 접근 (궤적 예측) |
|---------------------|------------------------|
| 단일 시점 예측: "이 사람의 뇌 나이는 65세" | 시간 변화 예측: "이 사람의 뇌는 연 1.5% 속도로 노화 중" |
| 스냅샷 정보 | 변화 속도/방향/가속도 |
| 개인 내 변화 포착 불가 | 개인 맞춤형 궤적 예측 |
| 정적 위험도 | 동적 개입 시점 제시 |

**핵심 통찰**: 임상적으로 actionable한 정보는 "현재 상태"가 아닌 "변화 궤적"이다. 치매 고위험군 선별에서 "뇌 연령 70세"보다 "연 2% 가속 노화 중, 3년 내 MCI 전환 예측"이 개입 결정에 유용하다.

### 두 번째 한계: 횡단면 학습의 종단 예측 실패

| 문제 | 근거 | 출처 |
|------|------|------|
| **횡단면 과소추정** | 횡단면 데이터로 학습된 모델은 실제 종단 변화를 과소추정 | PNAS 2023 |
| **회귀 평균 편향** | 어린 피험자 과대추정, 노인 과소추정 - "거의 모든 연구에서 보편적" | de Lange & Cole 2020 |
| **연령 의존성** | 보정 후에도 Brain Age Gap은 역연령에 의존 | eLife 2024 |
| **제한된 임상 유용성** | UK Biobank n>17,000에서 최대 효과크기 partial eta^2 = 0.0059 | Cole 2020 |
| **Brain-Age Paradox** | 단순 Ridge 회귀가 복잡한 CNN/Transformer보다 임상적 민감도 더 높음 | PLOS Biology 2024 |

## 1.2 기존 연구의 한계

### 경쟁 모델 현황 및 한계 (2024-2025)

| 모델 | 주요 기여 | 핵심 한계 |
|------|----------|----------|
| **NeuroSTORM (2025)** | 28.65M fMRI 프레임, Mamba 아키텍처 | 횡단면 데이터만, 궤적 예측 불가 |
| **BrainLM (ICLR 2024)** | Zero-shot 추론 능력 | fMRI 단일 모달리티, 종단 검증 없음 |
| **COMICAL (2024)** | 유전체-영상 통합 | Brain Age 중심, 궤적 접근 없음 |
| **Bethlehem et al. (Nature 2022)** | 100개 코호트 통합 뇌 성장 차트 | 인구 수준, 개인 예측 불가 |
| **Cole et al. (2017)** | Brain Age Gap 개념 제안 | 통계적 결함, 임상 유용성 제한 |

### 공통 한계 요약

1. **횡단면 편향**: 대부분 cross-sectional 데이터로 학습 → 개인 종단 변화 예측 실패
2. **단일 모달리티**: fMRI 또는 구조 MRI 단독 → 구조-기능-전기생리 통합 부재
3. **스케일 갭**: 수억 파라미터 수준 → LLM급(100B+) 스케일링 미달
4. **Brain Age 집착**: 궤적 예측이라는 더 가치 있는 목표 간과

## 1.3 핵심 갭 (1문장)

> **"기존 Brain Age Gap 연구는 단일 시점 '나이'만 예측하며, 발달-노화 '궤적(변화 속도/방향)'을 예측하는 멀티모달 대규모 파운데이션 모델이 부재하여, 임상적으로 actionable한 조기 개입 시점을 제시하지 못한다."**

### 갭의 구체화

| 측면 | 현재 상태 | 필요한 상태 |
|------|----------|------------|
| **예측 목표** | 단일 값 (Brain Age) | 궤적 함수 (시간에 따른 변화) |
| **데이터 활용** | 횡단면 회귀 | 종단 궤적 모델링 |
| **모델 규모** | 수억 파라미터 | 수백억 파라미터 (300B) |
| **모달리티** | 단일 (MRI 또는 EEG) | 3-모달 (MRI + EEG + 유전체) |
| **검증 코호트** | 서양인 중심 | 한국인 종단 코호트 |

## 1.4 창의성 및 도전성

### 창의성 (Originality)

| 창의성 | 기존 | 본 연구 |
|--------|------|--------|
| **1. 궤적 예측 패러다임** | Brain Age (스칼라 값) | **발달-노화 궤적 (시간 함수)** |
| **2. 모달리티별 100B FM** | 통합 수억 모델 | **fMRI 100B + EEG 100B + Genomic 100B** |
| **3. LLM 의미적 융합** | Early/Late fusion | **경량 LLM(100M) 기반 교차모달 어텐션** |
| **4. 한국인 종단 검증** | 서양인 횡단면 | **차병원 3K + 조선대 10K 종단 코호트** |
| **5. 다운스트림 다양성** | Brain Age만 | **8개 다운스트림 태스크 (궤적, 진단, Zero-shot)** |

### 도전성 (Challenge)

| 도전 과제 | 난이도 | 해결 전략 |
|----------|--------|----------|
| **300B 파라미터 학습** | 매우 높음 | 모달리티별 분리 학습 + 단계적 스케일업 + FSDP |
| **종단 궤적 모델링** | 높음 | Continuous Normalizing Flow + 개인화 사전분포 |
| **3-모달 융합** | 높음 | LLM 의미적 브릿지 + 교차모달 대조학습 |
| **한국인 도메인 적응** | 중간 | LoRA 기반 효율적 미세조정 |
| **실시간 임상 추론** | 중간 | 지식 증류 (300B → 3B) + INT8 양자화 |

## 1.6 연구의 학문적/사회적 의의

### 학문적 의의

> **"Brain Age를 예측하는 수억 파라미터 모델이 아닌, 발달-노화 궤적을 예측하는 300B 파운데이션 모델을 개발함으로써, 뇌 과학 AI의 패러다임을 '상태 추정'에서 '궤적 예측'으로 전환한다."**

| 기여 영역 | 구체적 기여 |
|----------|------------|
| 신경과학 | 발달-노화 연속체 가설의 대규모 AI 기반 정량적 검증 |
| AI/ML | 뇌영상 도메인 최대 규모(300B) 파운데이션 모델 아키텍처 |
| 임상 의학 | 궤적 기반 개인화 위험 예측 및 개입 시점 제시 |

### 사회적 의의

| 기대 효과 | 설명 |
|----------|------|
| **치매 조기 예측** | 궤적 기반 고위험군 선별 → 예방적 개입으로 의료비 절감 |
| **한국인 바이오마커** | 13,000명 한국인 뇌 건강 표준 제시 |
| **기술 경쟁력** | 세계 최대 규모 뇌 FM → 국내 의료 AI 경쟁력 확보 |
