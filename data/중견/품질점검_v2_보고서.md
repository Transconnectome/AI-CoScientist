## Red Team 핵심 질문 검증

### Q1: "Brain Age Gap과 뭐가 다른가?"

**답변 가능 여부**: **YES**

| 항목 | Brain Age Gap | 본 연구 (궤적 예측) |
|------|---------------|-------------------|
| 예측 대상 | 단일 값 (스칼라) | 시간 함수 (궤적) |
| 임상 가치 | "뇌 나이 65세" | "연 1.5% 가속 노화, 3년 내 MCI 전환 예측" |
| 데이터 활용 | 횡단면 회귀 | 종단 궤적 모델링 |
| 통계적 문제 | 회귀 평균 편향, eta^2=0.0059 | CNF 기반 개인화 궤적 |

**제안서 내 위치**: Block 1 (1.1, 1.3), Block 2 (2.2)

### Q2: "300B 학습 가능한가?"

**답변 가능 여부**: **YES**

| 근거 | 설명 |
|------|------|
| **아키텍처** | 모달리티별 분리 학습 (각 100B) → 융합층 100M |
| **데이터** | 70K MRI + 30Kh EEG + UK Biobank 유전체 |
| **컴퓨팅** | A100 x 512 클라우드 임대 (연 6,000만원) |
| **단계적** | 1B → 10B → 50B → 100B 스케일업 |
| **기술** | FSDP, FlashAttention-2, Gradient Checkpointing |

**제안서 내 위치**: Block 3 (3.1 목표 1)

**리스크 대응**: 학습 실패 시 모달리티별 50B로 축소

---

### Q3: "NeuroSTORM, BrainLM 대비 차별점?"

**답변 가능 여부**: **YES**

| 경쟁자 | 그들의 강점 | 본 연구 차별점 |
|--------|------------|--------------|
| NeuroSTORM | 28.65M fMRI 프레임, Mamba | **EEG 통합** (그들은 fMRI only) |
| BrainLM | Zero-shot 추론 | **유전체 통합** (그들은 영상 only) |
| COMICAL | 유전체-영상 | **실시간 추론 시스템** (그들은 연구용) |
| 모든 경쟁자 | 횡단면 데이터 | **종단 궤적 예측** |
| 모든 경쟁자 | 서양인 중심 | **한국인 13K 종단 코호트** |

**제안서 내 위치**: Block 1 (1.2), Block 2 (2.2)

---

### Q4: "한국 데이터 경쟁 우위 명확?"

**답변 가능 여부**: **YES**

| 코호트 | 규모 | 특징 | 활용 |
|--------|------|------|------|
| 차병원 | 3,000명 | 8-25세, 종단, 발달 | 목표 2 |
| 조선대 | 10,000명 | 50-90세, 종단, 치매 | 목표 3 |
| **총계** | 13,000명 | 한국인 특이적 | 도메인 적응 |

**차별화 포인트**:
- 글로벌 모델(UK Biobank, ABCD)은 서양인/유럽계 중심
- 한국인 종단 데이터로 인종 편향 극복
- 발달(차병원) + 노화(조선대) = 전생애주기 커버

**제안서 내 위치**: Block 2 (2.4-2.5), Block 3 (3.2), Block 4 (4.4)
