## Phase 1: Block 2 작성 - 연구 목표 및 내용 (Day 1-2)

### 1.1 목표

> Block 2는 제안서의 **심장**. Red Team Pivot을 여기서 반영.
> 평가 가중치: **40%** (창의성/도전성과 공유)

### 1.2 작성 순서

```
Step 1.1: 최종 목표 재정의 (30분)
    ├── Before: "Brain Age Gap 예측"
    └── After: "발달-노화 궤적 예측 파운데이션 모델"

Step 1.2: 4개 목표 구조 재설계 (2시간)
    ├── 목표 1: 멀티모달 파운데이션 모델 (스케일 명시)
    ├── 목표 2: 발달 궤적 예측 (차병원 if 가능)
    ├── 목표 3: 노화/치매 궤적 예측 (조선대 if 가능)
    └── 목표 4: 임상 추론 + 다운스트림 태스크

Step 1.3: 선행연구 차별성 표 업데이트 (1시간)
    ├── NeuroSTORM, BrainLM, COMICAL 추가
    └── 본 연구 차별점 명확화

Step 1.4: 5년 로드맵 업데이트 (1시간)
    └── 궤적 예측 중심으로 재구성

Step 1.5: 목표별 세부 내용 작성 (3시간)
    ├── 각 목표: 핵심 질문 + 세부 과제 + 산출물 + 지표
    └── 다운스트림 태스크 목록 포함
```

## Phase 2: Block 3 작성 - 추진전략/방법 (Day 3-5)

### 2.1 목표

> Block 3은 제안서의 **근육**. 기술적 실현가능성 입증.
> 평가 가중치: **30%** (방법론 적합성)

### 2.2 작성 순서

```
Step 2.1: 모델 아키텍처 재설계 (3시간)
    ├── 모델 스케일: 5B → 10-20B 근거
    ├── 모달리티별 인코더 설계
    ├── 융합 레이어 아키텍처
    └── Figure 2 업데이트 필요 여부 검토

Step 2.2: 데이터 전략 업데이트 (2시간)
    ├── 기존: UK Biobank + ABCD + HCP
    ├── 추가: 차병원 발달 코호트 (if 가능)
    ├── 추가: 조선대 치매 코호트 (if 가능)
    └── 연령 갭 해결 전략 (25-45세)

Step 2.3: 목표별 상세 방법론 (4시간)
    ├── 목표 1: 사전학습 전략 (MAE, 대조학습)
    ├── 목표 2: 발달 궤적 예측 방법
    ├── 목표 3: 노화 궤적 예측 방법
    └── 목표 4: 추론 최적화 + 다운스트림 태스크

Step 2.4: 다운스트림 태스크 방법론 (2시간)
    ├── 질환 진단 (AD, PD, 조현병)
    ├── Zero-shot 추론
    ├── Few-shot 학습
    └── (Brain Age Gap - 벤치마크로만)

Step 2.5: 리스크 + 대안 프로토콜 (1시간)
    ├── 스케일링 실패 시 대안
    ├── 한국 코호트 확보 실패 시 대안
    └── 궤적 예측 정확도 미달 시 대안

Step 2.6: Go/No-Go 기준 업데이트 (1시간)
    ├── 기존: MAE < 3.0년
    ├── 추가: 궤적 예측 RMSE
    ├── 추가: 질환 진단 AUC
    └── 추가: Zero-shot 성능

Step 2.7: 연구비/인력 적정성 검토 (1시간)
    └── 10-20B 학습을 위한 GPU 비용 재산정
```

### 2.3 Block 3 핵심 변경 사항

| 항목 | Before | After |
|------|--------|-------|
| 모델 스케일 | 5B | 10-20B (단계적) |
| 학습 전략 | 단일 모델 | 모달리티별 사전학습 → 융합 |
| 핵심 태스크 | Brain Age Gap | **궤적 예측 + 다운스트림 5종** |
| Go/No-Go | MAE만 | MAE + 궤적 RMSE + AUC |
| 리스크 대안 | 일반적 | 스케일링, 데이터, 정확도 별도 |

### 2.4 다운스트림 태스크 설계 (신규 섹션)

```markdown
### 다운스트림 태스크 설계

| 태스크 | 데이터 | 평가 지표 | 목표 |
|--------|--------|----------|------|
| **발달 궤적 예측** | 차병원 종단 | RMSE, 상관계수 | r > 0.5 |
| **노화 궤적 예측** | 조선대 종단 | RMSE, 상관계수 | r > 0.5 |
| **AD 진단** | UK Biobank + 조선대 | AUC, 민감도 | AUC > 0.90 |
| **인지 저하 예측** | KoGES | AUC | AUC > 0.80 |
| **Zero-shot 추론** | 외부 데이터셋 | Top-1 Accuracy | > 70% |
| **Brain Age** (벤치마크) | UK Biobank | MAE | < 2.5년 |
```
