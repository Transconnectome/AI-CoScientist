# 2. 연구과제의 목표 및 내용

## 2.1 연구과제의 최종 목표

> **발달-노화 궤적 예측 멀티모달 파운데이션 모델 개발**:
> 생애주기 전체(8-90세)의 뇌영상(fMRI/sMRI)-뇌파(EEG)-유전체 데이터를 모달리티별 대규모 파운데이션 모델(fMRI 100B, EEG 100B, Genomic 100B)로 사전학습하고, 경량 LLM(100M)을 의미적 융합층으로 활용하여 **발달기 뇌 성숙 궤적**과 **노화기 인지 저하 궤적**을 개인 수준에서 예측하며, 다양한 다운스트림 태스크(질환 진단, 치매 전환 예측, 치료 반응)에서 SOTA 성능을 달성하는 임상 추론 시스템을 구축한다.

## 2.2 선행연구 분석 및 차별성

### 경쟁 모델 현황 (2024-2025)

| 구분 | NeuroSTORM (2025) | BrainLM (ICLR 2024) | COMICAL (2024) | BrainSegFounder (2024) | **본 연구** |
|------|-------------------|---------------------|----------------|------------------------|------------|
| **데이터 규모** | 28.65M 프레임, 50K+ 피험자 | 6,700시간 fMRI | 40,426명 (UK Biobank) | 41,400명 | **70K MRI + 30Kh EEG + 13K 유전체** |
| **모달리티** | fMRI 단일 | fMRI 단일 | MRI + 유전체 (SNP) | MRI (T1/T2) | **fMRI + EEG + 유전체 3-모달** |
| **모델 스케일** | 미공개 (Mamba) | 수억 파라미터 | 미공개 | VGG-16 기반 | **~300B (모달리티별 100B)** |
| **핵심 태스크** | 연령/성별/질환 예측 | Zero-shot 추론 | 유전체-영상 연관 | 3D 분할 | **궤적 예측 (발달+노화)** |
| **종단 예측** | 횡단면 | 횡단면 | 횡단면 | 횡단면 | **종단 궤적 예측** |
| **한국인 검증** | 없음 | 없음 | 없음 | 없음 | **차병원 3K + 조선대 10K** |
| **임상 추론** | 연구용 | 연구용 | 연구용 | 연구용 | **실시간 임상 서비스** |

### 기존 연구의 핵심 한계

1. **횡단면 편향**: 대부분 횡단면(cross-sectional) 데이터로 학습 → 개인 수준 종단(longitudinal) 변화 과소추정
2. **Brain Age Gap의 통계적 결함**: 회귀 평균 편향(어린 피험자 과대추정, 노인 과소추정), 제한된 임상 유용성 (최대 η²=0.0059)
3. **단일 모달리티**: fMRI 또는 구조 MRI 단독 → 뇌 구조-기능-전기생리 통합 연계 부재
4. **스케일 갭**: 현존 뇌 파운데이션 모델은 수억 파라미터 수준 → LLM 수준(100B+) 스케일링 미달

### 본 연구의 핵심 차별화

| 차별화 요소 | 기존 모델 | 본 연구 |
|------------|----------|--------|
| **예측 목표** | 단일 시점 "나이" (Brain Age) | **시간에 따른 "궤적" (변화 속도/방향)** |
| **학습 패러다임** | 횡단면 데이터 회귀 | **종단 데이터 궤적 모델링** |
| **모델 규모** | ~수억 파라미터 | **~300B 파라미터 (모달리티별 대규모)** |
| **융합 방식** | Early/Late fusion | **LLM 기반 의미적 융합 (100M)** |
| **검증 코호트** | 서양인 중심 (UK Biobank) | **한국인 종단 코호트 (13K)** |

## 2.3 연구 핵심 질문 및 가설

### 핵심 가설

> **"발달기(8-25세) 뇌 구조/기능/전기생리 성숙 궤적의 개인차가 노화기(50세+) 인지 저하 및 신경퇴행 궤적을 결정한다."**

### 연구 질문 (4개 목표와 연결)

| 목표 | 핵심 질문 |
|------|----------|
| **목표 1** | 70,000+ 뇌영상과 30,000시간 뇌파를 모달리티별 100B 파라미터로 학습하면 범용 뇌 표현을 획득할 수 있는가? |
| **목표 2** | 발달기 뇌 성숙 궤적(피질 두께, 백질 성숙, 기능적 연결성 변화)을 개인 수준에서 예측할 수 있는가? |
| **목표 3** | 노화기 인지 저하 및 치매 전환 궤적을 조기에 예측하여 개입 시점을 제시할 수 있는가? |
| **목표 4** | 대규모 파운데이션 모델을 임상 현장에서 실시간으로 배포하고 다양한 다운스트림 태스크에 적용할 수 있는가? |

## 2.4 5년 연구 로드맵 (4개 목표 구조)

```
1-2차년도: 목표 1 (모달리티별 파운데이션 모델)
    ├── fMRI Foundation Model (100B): 4D Swin Transformer + MAE
    ├── EEG Foundation Model (100B): DIVER 기반 채널등변 인코더
    ├── Genomic Foundation Model (100B): PRS + Transformer
    └── 융합층 LLM (100M): 의미적 브릿지

2-3차년도: 목표 2 (발달 궤적 예측 - 차병원 코호트)
    ├── 발달기 뇌 성숙 궤적 학습 (3,000명 종단)
    ├── 피질 두께/백질 성숙/연결성 변화 예측
    └── 신경발달장애 조기 예측

3-4차년도: 목표 3 (노화 궤적 예측 - 조선대 코호트)
    ├── 노화기 인지 저하 궤적 학습 (10,000명 종단)
    ├── 치매 전환 시점 예측
    └── 한국인 특이적 바이오마커 도출

4-5차년도: 목표 4 (임상 추론 및 다운스트림)
    ├── 모델 경량화 (지식 증류)
    ├── 다운스트림 태스크: AD/PD 진단, 치료 반응, Zero-shot
    └── 실시간 임상 서비스 배포
```

## 2.5 목표별 상세 내용

### 목표 1: 모달리티별 대규모 파운데이션 모델 개발 (1-2차년도)

**핵심 질문**: "70,000+ 뇌영상과 30,000시간 뇌파를 모달리티별 100B 파라미터로 학습하면 범용 뇌 표현을 획득할 수 있는가?"

#### 모델 아키텍처

| 모달리티 | 아키텍처 | 파라미터 | 사전학습 전략 | 출력 |
|----------|----------|----------|--------------|------|
| **fMRI** | 4D Swin Transformer | 100B | Masked Autoencoder (75%) | 2048-dim |
| **EEG** | DIVER 채널등변 인코더 | 100B | 시간-채널 마스킹 | 2048-dim |
| **Genomic** | PRS Transformer | 100B | 대조학습 | 2048-dim |
| **융합층** | LLM (GPT-style) | 100M | 의미적 정렬 | 통합 표현 |

#### 세부 과제

| 세부 과제 | 설명 | 산출물 |
|----------|------|--------|
| 1.1 데이터 통합 | UK Biobank(50K) + ABCD(12K) + HCP(2.5K) + TUEG(30Kh) | 통합 데이터셋 N>70K |
| 1.2 fMRI FM | 4D Swin Transformer 100B 사전학습 | fMRI 파운데이션 |
| 1.3 EEG FM | DIVER 기반 100B 채널등변 모델 | EEG 파운데이션 |
| 1.4 Genomic FM | UK Biobank 유전체 + PRS 100B | Genomic 파운데이션 |
| 1.5 LLM 융합층 | 100M 의미적 브릿지 학습 | 3-모달 통합 |

**성공 지표**:
- 선형 탐침 연령 예측 MAE < 2.5년
- 교차모달 검색 정확도 > 80%
- Brain Age (벤치마크) MAE < 2.5년

### 목표 2: 발달 궤적 예측 시스템 (2-3차년도)

**핵심 질문**: "발달기 뇌 성숙 궤적(피질 두께, 백질 성숙, 기능적 연결성 변화)을 개인 수준에서 예측할 수 있는가?"

#### 차병원 발달 코호트 활용

| 항목 | 내용 |
|------|------|
| **코호트 규모** | 3,000명 (아동-청소년, 8-25세) |
| **종단 추적** | 2-5년 추적, 2-3회 반복 측정 |
| **모달리티** | sMRI + fMRI + EEG + 임상 |
| **접근성** | 협력 확정 (MOU 예정) |

#### 발달 궤적 예측 태스크

```
발달 궤적 예측 (Killer Task):
├── 1. 피질 두께 변화 속도 예측
│      - 전두엽 성숙 궤적
│      - 개인별 성숙 시점 예측
├── 2. 백질 성숙 궤적 예측
│      - FA/MD 변화 곡선 모델링
│      - 비정상 성숙 패턴 탐지
├── 3. 기능적 연결성 발달 패턴
│      - DMN/SN/FPN 발달 궤적
│      - 네트워크 통합 시점 예측
└── 4. 인지 발달 milestone 예측
       - 발달 지연/가속 탐지
       - 신경발달장애 조기 예측
```

#### 세부 과제

| 세부 과제 | 설명 | 산출물 |
|----------|------|--------|
| 2.1 데이터 수집 | 차병원 코호트 3,000명 데이터 획득 | 종단 데이터셋 |
| 2.2 궤적 모델링 | 연속 정규화 흐름(CNF) 기반 궤적 학습 | 궤적 예측 모델 |
| 2.3 발달 바이오마커 | 발달 지연/가속 바이오마커 도출 | 바이오마커 목록 |
| 2.4 임상 검증 | 신경발달장애 예측 성능 검증 | 검증 논문 |

**성공 지표**:
- 궤적 예측 RMSE < 0.15 (정규화)
- 발달-궤적 상관계수 r > 0.5
- 신경발달장애 예측 AUC > 0.80

### 목표 3: 노화/치매 궤적 예측 시스템 (3-4차년도)

**핵심 질문**: "노화기 인지 저하 및 치매 전환 궤적을 조기에 예측하여 개입 시점을 제시할 수 있는가?"

#### 조선대 치매 코호트 활용

| 항목 | 내용 |
|------|------|
| **코호트 규모** | 10,000명 (중년-노인, 50-90세) |
| **종단 추적** | 5-10년 추적, 다회 반복 측정 |
| **모달리티** | sMRI + fMRI + 인지검사 + 유전체 |
| **접근성** | 협력 확정 |

#### 노화 궤적 예측 태스크

```
노화/치매 궤적 예측 (Killer Task):
├── 1. 해마 위축 속도 예측
│      - 개인별 위축 궤적 모델링
│      - 비정상 위축 조기 탐지
├── 2. 인지 저하 궤적 예측
│      - MCI 전환 시점 예측
│      - 치매 전환 위험도 추정
├── 3. 백질 고강도 신호 진행 예측
│      - WMH 축적 속도 모델링
│      - 혈관성 치매 위험 예측
└── 4. 한국인 특이적 노화 바이오마커
       - 서양인 모델과의 차이 분석
       - 한국인 정상 노화 기준선 도출
```

#### 세부 과제

| 세부 과제 | 설명 | 산출물 |
|----------|------|--------|
| 3.1 데이터 수집 | 조선대 코호트 10,000명 데이터 획득 | 종단 데이터셋 |
| 3.2 노화 궤적 모델 | 인지 저하 궤적 예측 모델 개발 | 궤적 예측 모델 |
| 3.3 치매 전환 예측 | MCI→AD 전환 시점 예측 | 전환 예측 모델 |
| 3.4 한국인 검증 | 서양인 모델 대비 한국인 성능 검증 | 검증 논문 |

**성공 지표**:
- 노화 궤적 예측 RMSE < 0.15 (정규화)
- 치매 전환 예측 AUC > 0.85
- 한국인 vs 서양인 성능 격차 < 5%

### 목표 4: 임상 추론 및 다운스트림 태스크 (4-5차년도)

**핵심 질문**: "대규모 파운데이션 모델을 임상 현장에서 실시간으로 배포하고 다양한 다운스트림 태스크에 적용할 수 있는가?"

#### 다운스트림 태스크 설계

| 태스크 | 데이터 | 평가 지표 | 목표 |
|--------|--------|----------|------|
| **발달 궤적 예측** | 차병원 종단 | RMSE, r | r > 0.5 |
| **노화 궤적 예측** | 조선대 종단 | RMSE, r | r > 0.5 |
| **AD 진단** | UK Biobank + 조선대 | AUC, 민감도 | AUC > 0.90 |
| **PD 진단** | 외부 검증 | AUC | AUC > 0.85 |
| **치매 전환 예측** | 조선대 MCI | Hazard Ratio | HR > 2.0 |
| **Zero-shot 추론** | 외부 데이터셋 | Top-1 Accuracy | > 70% |
| **Few-shot 학습** | n=100 신규 태스크 | AUC | > 0.75 |
| **Brain Age (벤치마크)** | UK Biobank | MAE | < 2.5년 |

#### 세부 과제

| 세부 과제 | 설명 | 산출물 |
|----------|------|--------|
| 4.1 모델 최적화 | 지식 증류 (300B → 3B), INT8 양자화 | 경량화 모델 |
| 4.2 추론 서비스 | TensorRT + Triton 서버 구축 | 추론 API |
| 4.3 다운스트림 검증 | 8개 태스크 성능 검증 | 검증 결과 |
| 4.4 임상 파일럿 | 협력 병원 2,000명 대상 실증 | 파일럿 보고서 |

**성공 지표**:
- 추론 지연시간 < 30초
- 다운스트림 평균 AUC > 0.85
- 임상의 만족도 > 4.0/5.0
