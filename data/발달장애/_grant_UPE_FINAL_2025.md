# 소아 발달장애 멀티모달 데이터 기반 AI 파운데이션 모델 구축을 통한 임상 예후예측 및 조기 맞춤재활 플랫폼 개발

**AI Foundation Model Based on Multimodal Pediatric Neurodevelopmental Data for Clinical Outcome Prediction and Early Precision Rehabilitation**

---

## 연구의 필요성

국내에 등록된 발달장애인은 약 26만명으로 매년 지속적으로 7~8천명씩 증가하는 추세이나, 진단을 받는 시기는 치료가 필요한 시기에 비해 늦음. 대다수는 대동작, 미세동작, 언어, 인지, 자조 및 사회적 능력 등의 발달 도메인에서 두가지 이상 유의하게 지체된 전반적 발달지연에 해당하며 원인 질환 및 중재의 적정성에 따라 장기적 예후가 결정됨. 현재까지 소아기 발달장애 연구는 대부분 단일 데이터(특정 기능점수, 뇌 MRI, 또는 유전체 중 하나)에 기반하여 이루어졌을 뿐 아니라, 단일시점의 snapshot 데이터 분석에 머물러 있음. 즉, 임상적으로 여러 발달 도메인을 측정한 데이터가 확보되지 않았고, 발달 중 변화가 많은 어린 나이부터 종단적인 관찰을 하여 장기적 임상 outcome까지 확보된 연구들이 부재함. 뚜렷한 병변만을 알아보고자 하는 루틴 뇌 MRI로는 한계가 있어 뇌신경로를 정량화하는 확산텐서영상이 활용될 수 있고, next generation sequencing 등으로 세밀한 유전자 분석이 가능해졌으나, 아직 그 결과들로서 정확한 예후예측을 하기에는 연결된 임상데이터가 충분하지 않음. 본 연구에서는 어린 나이부터 장기적으로 확보된 멀티모달 임상 데이터와 퍼블릭데이터를 활용하여 거대 AI 파운데이션 모델을 구축하여 정밀개별 의료를 실현하고자 함. 이를 통해 예후를 예측하고, 조기에 맞춤형 재활 포함 중재전략을 제공할 수 있도록 할 것이며, 이를 임상적으로 검증하고 새로이 발견된 유전자 이상을 동물모델로 검증하고자 함.

## 연구내용

### 궁극적 목표

본 연구에서는 발달장애를 조기에 진단하고 임상 경과를 예측할 수 있는 바이오마커들이 발굴될 것임. 또한, 파운데이션AI가 구축되면 이를 활용하여, 실제 임상에서 개인별 예후 예측과 재활 등 최적의 치료적 중재전략이 3세 미만 어린 나이에서부터 제시됨으로써 최선의 임상적인 효과를 발생시킬 것으로 기대함. 이로써 현재는 전반적 발달지연으로만 분류되고 있는 자폐스펙트럼, 지적장애, 각종 유전자이상과 연관된 발달장애, 뇌성마비 등이 진단이 어려운 어린 시기에서부터 적합한 진료가 가능해 질 것임.

**정량적 목표 (보수적 추정)**:
- **1차 스크리닝 민감도**: **≥90%** (Sensitivity), 특이도 ≥70% (Specificity)
- **2차 분류 AUC**: **0.78-0.82** (진단 보조 도구로 활용)
- 3세 미만 조기중재율: 15% → **45%** (3배 향상, 보수적)
- 진단-치료 시작 기간: 평균 24개월 → **12개월** (50% 단축)

**핵심 전략 변경**: 본 연구는 "진단(Diagnosis)"이 아닌 **"스크리닝(Screening)"**을 1차 목표로 함. 이는 희귀 질환 특성상 높은 민감도(Sensitivity)를 우선하여 조기 발견율을 극대화하고, 2차 다기관 정밀 검사로 진단을 확정하는 2단계 접근법임.

### 방법 1. 멀티모달 데이터의 체계적 축적

- 약 20년 이상 **3천 명 이상** 소아에서 장기적 종단적으로 발달의 여러 측면들(대동작, 미세협응동작, 시지각, 언어, 지능, 사회성, 행동이상, 감각통합 기능 등)을 측정한 점수의 체계적 축적
- 약 **2천5백례 이상**의 뇌내 백질 발달을 파악할 수 있는 확산텐서영상(DTI)의 처리와 데이터화
- 퍼블릭 소아 뇌 확산텐서영상의 처리와 분석을 위한 데이터화
- 유전자 검사 결과들과 뇌영상 및 다종 임상 데이터 등의 연관성 파악

**현실적 데이터 품질 평가**:
- 완전 멀티모달 데이터 (4개 모달리티 이상): **800-1,200명**
- 종단 추적 완료율: 약 **60%** (1,800명 유효)
- 통계적 검정력: **85%** (n=1,200 기준, α=0.05, effect size=0.3)

### 방법 2. NeuroX-Fusion 1B: 발달장애 특화 멀티모달 Foundation Model 구축

#### 2.1 현실적 아키텍처 설계

본 과제는 **1B 파라미터 최적화 전략**을 채택함. 이는 1,200명 규모 데이터셋에서 과적합(overfitting)을 방지하면서 충분한 표현력을 확보하는 현실적 선택임 (데이터:파라미터 비율 ≈ 1:800, 권장 범위 내).

**2단계 스크리닝-분류 모델 아키텍처**:

| 단계 | 기간 | 모델 | 목표 | 평가 지표 |
|------|------|------|------|----------|
| **Stage 1: Binary Screening** | M1-24 | **1B Medical LLM + Q-Former** | 발달장애 유/무 선별 | Sensitivity ≥90%, Specificity ≥70% |
| **Stage 2: Multiclass Classification** | M25-48 | **1B Fine-tuned + CoT** | 4개 하위분류 (ASD/ID/CP/Other) | Macro-F1 ≥0.65 |
| **Stage 3: Severity Prediction** | M49-60 | **1B + LoRA + Explanation** | 중증도/예후 예측 + 근거 생성 | R² ≥0.50 |

**핵심 아키텍처 혁신: LLM 통합 멀티모달 의료 AI**

본 과제는 최신 **Medical Multimodal LLM** 아키텍처를 채택하여, 단순 분류를 넘어 **임상 추론(Clinical Reasoning)과 설명가능성(Explainability)**을 확보함. 이는 Google Med-Gemini (2024), Microsoft LLaVA-Med (2024), NeuGPT (2024) 등 최신 연구 동향을 반영한 설계임.

1. **Spatiotemporal Manifold Learning**: 시공간 다양체(Manifold) 기반 뇌 발달 궤적 모델링

   **수학적 정의**: 발달 궤적 z(t)를 d차원 Riemannian manifold M 상의 geodesic으로 모델링:
   ```
   z(t) = Exp_{z₀}(t · v₀),  where z₀ ∈ M, v₀ ∈ T_{z₀}M

   발달 이상 탐지: d_M(z(t), μ(t)) > τ  (μ: 정상 발달 중심 궤적)
   거리 메트릭: d_M은 Fréchet distance 또는 Dynamic Time Warping
   ```
   - 개인별 발달 궤적을 Latent Trajectory로 표현
   - 비정상 발달 패턴 조기 감지 (정상 분포 대비 geodesic 이탈도 측정)

2. **NeuGPT-style Neural Signal Tokenization** (Yang et al., arXiv 2024):

   EEG, fMRI 등 신경 신호를 LLM이 처리할 수 있는 **discrete token sequence**로 변환하는 혁신적 접근:

   **NeuTokenizer 아키텍처**:
   ```
   Neural Signal x(t) → Encoder → Residual Vector Quantization (RVQ) → Discrete Tokens

   Codebook: C = {c₁, c₂, ..., c_K},  K = 8192 (vocabulary size)
   Quantization: z_q = argmin_{c∈C} ||z_e - c||₂

   Output: Token sequence T = [t₁, t₂, ..., t_L] compatible with LLM input
   ```

   **장점**:
   - 이기종 신경 신호(EEG, MEG, fMRI, fNIRS) 통합 처리
   - LLM의 언어 모델링 능력을 신경 신호 분석에 활용
   - Brain-to-Text decoding SOTA: BLEU-1 6.94→12.92 (+86% 향상)

3. **Q-Former 기반 Vision-Language Bridge** (BLIP-2/LLaVA-Med 계열):

   MRI/DTI 3D 영상을 LLM과 연결하는 **Query Transformer** 아키텍처:

   **Q-Former 메커니즘**:
   ```
   Image Features: F_img = ViT(MRI),  F_img ∈ ℝ^(N×D)
   Learnable Queries: Q ∈ ℝ^(32×D)  (32개 query tokens)

   Cross-Attention: Q' = softmax(Q·K^T/√d)·V,  where K,V = Linear(F_img)
   Output: Z_visual = MLP(Q') ∈ ℝ^(32×D_llm)  → LLM embedding space
   ```

   **의료 영상 적용 성과**:
   - ClinicalBLIP: Radiology report generation SOTA
   - LLaVA-Med: VQA-RAD, SLAKE 최고 성능
   - **54배 적은 학습 파라미터** (vs full fine-tuning)

4. **Medical LLM Backbone with Chain-of-Reasoning**:

   임상 추론과 설명 생성을 위한 **의료 특화 LLM** 통합:

   **후보 Base Models** (1B급):
   - **Qwen2-Med 1.5B**: 중국어/영어 의료 데이터 학습, 한국어 fine-tuning 가능
   - **BioMistral 7B → Distilled 1B**: 생의학 도메인 특화
   - **Meditron 7B → LoRA**: 의료 QA 최적화

   **Chain-of-Reasoning (CoR) 프롬프트 설계**:
   ```
   Input: [MRI_tokens] [EEG_tokens] [Clinical_data] [Query: "이 환아의 발달장애 위험도는?"]

   CoR Output:
   1. 뇌영상 소견: "좌측 측두엽 백질 FA 값 0.32로 연령 대비 -1.5 SD..."
   2. EEG 분석: "세타파 우세, N170 지연 150ms로 사회인지 처리 지연 시사..."
   3. 임상 지표: "ADOS-2 비교 점수 7점, 언어발달 12개월 지연..."
   4. 종합 판단: "ASD 고위험군 (위험도 85%), 조기 중재 권고"
   5. 근거 요약: "DTI FA↓ + N170 지연 + ADOS 절단점 초과의 3중 일치"
   ```

   **설명가능성 확보**: 임상의가 AI 판단의 근거를 자연어로 확인 가능

5. **MedPatch 스타일 Confidence-guided Fusion** (arXiv 2025):

   임상 데이터의 heterogeneity와 missing modality 문제를 해결하는 다단계 융합:

   ```
   Token Confidence: conf(t_i) = softmax(MLP(t_i))
   Missingness Indicator: m = [m₁, m₂, m₃, m₄] ∈ {0,1}⁴  (각 모달리티 가용성)
   Adaptive Fusion: z = Σ_i (m_i · conf(t_i) · t_i) / Σ_i (m_i · conf(t_i))
   ```

   - **Missingness-aware Module**: 누락 모달리티 자동 감지 및 가용 정보 기반 추론
   - **MIMIC-IV 벤치마크 SOTA**: In-hospital mortality, phenotyping 최고 성능

6. **Parameter-Efficient Fine-Tuning (PEFT)**:
   - LoRA (r=8-16): 전체 파라미터의 **0.5-1%**만 학습
   - 비용 절감: 전체 재학습 대비 **90% 감소**
   - 근거: Hu et al., 2021, ICLR

#### 3.2 Missing Modality 처리 전략

실제 임상 환경에서 모든 모달리티가 완비되지 않는 경우가 빈번함. 본 연구는 **MedPatch 기반 Missingness-aware Fusion** 전략을 채택:

| 전략 | 방법 | 적용 시점 |
|------|------|----------|
| **학습 시 마스킹** | 30% 확률로 각 모달리티 랜덤 드롭아웃 | Pre-training |
| **Missingness-aware Module** | 누락 모달리티 indicator 벡터 m_i ∈ {0,1} 주입 | All stages |
| **Confidence-guided Fusion** | 토큰별 신뢰도 기반 가중 풀링 | Joint fusion |
| **LLM Context Adaptation** | 누락 모달리티 명시적 프롬프트 처리 | LLM inference |
| **Graceful Degradation** | 최소 2개 모달리티로 동작, 성능 저하 ≤12% | Clinical deployment |

**근거**: MedPatch (arXiv 2025) MIMIC-IV SOTA; LLaVA-Med (Microsoft 2024) missing modality robustness

**모달리티별 특징 차원**:
| 모달리티 | 특징 수 | 주요 바이오마커 |
|----------|---------|----------------|
| Structural MRI | 83 | 피질 두께, 피질하 부피 |
| Clinical | 45 | ADOS-2, 발달 이정표 |
| EEG | 32 | 세타파 활성, N170 지연 |
| Genomics | 27 | PRS 3개 + Rare variants |
| **총합** | **187** | → 512 dim fusion |

#### 3.3 바이오마커 발굴 전략

- 임상적 표현 특성, 뇌영상, 유전자(VUS 포함) 소견 등에서 예후와 관련된 바이오마커 발굴
- 바이오인포매틱스 기술 활용으로 퍼블릭데이터와 기확보된 데이터로 이상 유전체 후보 발굴
- 발굴된 유전체 이상을 **제브라피쉬 Rapid Screening Preview** 시스템으로 사전 검증 후 임상 검증 진행
- 발달장애 별 특성에 따른 장기적 outcome 예측을 위하여 장애의 종류, 심각도 구분과 각 경우의 중재가 필요한 영역들을 파악

### 방법 4. 발굴된 바이오마커의 실증적 검증과 치료적 중재 전략 제시

#### 4.1 3단계 임상 검증 프로토콜

| 단계 | 기간 | 대상 | 목표 | 평가 지표 |
|------|------|------|------|----------|
| **Validation 1** | M12-24 | 후향적 코호트 n=500 | Stage 1 내부 검증 | Sens ≥88%, Spec ≥68% |
| **Validation 2** | M24-36 | 전향적 코호트 n=300 | Stage 1 외부 검증 | Sens ≥85%, Spec ≥65% |
| **Validation 3** | M36-48 | 다기관 검증 n=200 | Stage 1+2 일반화 | Sens ≥80%, F1 ≥0.55 |

#### 4.2 치료적 중재 전략

- 정제한 데이터를 활용하여 발달장애 분류 및 진단을 위한 임상, 뇌영상, 유전체 데이터의 모달리티별 AI 모델 개발
- 전향적 코호트에서 발굴된 바이오마커 적용으로 조기중재를 통하여 임상적 유효성 평가
- 재활중재가 필요한 영역과 심각도를 고려한 중재 전략과 효과적인 컨텐츠 제시
- 향후 추가적 개발을 위하여 뇌파와 행동(놀이 활동 등)을 녹화한 데이터를 확보하고, 이를 AI 파운데이션 모델에 추가하여 타 데이터들과의 연관성 파악, 정밀진료의 정확성 증대

### 방법 5. 제브라피쉬 Rapid Screening Preview 시스템

**위치 재정립**: 본 연구에서 제브라피쉬는 **주요 검증 수단이 아닌 "Rapid Screening Preview"** 역할을 수행함.

**목적**: 임상 검증 전 유전체 후보 바이오마커의 신경학적 관련성을 **빠르게 선별(screening)**하여 임상 검증 자원의 효율적 배분을 지원

**프로토콜**:
1. AI 모델 발굴 유전체 후보 → 제브라피쉬 형질전환
2. 행동/신경 표현형 관찰 (2-3개월)
3. 양성 결과만 임상 검증 파이프라인으로 진행
4. **예상 필터링률**: 70-80% (임상 검증 효율 3-4배 향상)

제브라피쉬(Danio rerio)는 배아조작, 형질전환, 유전자녹아웃 모두 가능하며, 사람 유전자와 80% 이상 염기서열 유사성을 지님. 3개월 성체화, 투명 체외 수정으로 대량 스크리닝에 최적화됨.

## 기대효과

### 과학기술적 영향
- 국내 최초 발달장애 특화 **LLM 통합 멀티모달 AI 모델**
- NeuGPT-style Neural Tokenization + Medical LLM 융합 원천기술 확보
- SCI 논문 15편+ (IF 5.0 이상, Nature Medicine/Lancet Digital Health 급 1편+)
- 핵심 특허 5-10건 (AI 모델, 바이오마커, 설명가능 추론 시스템)
- K-NeuroX 발달장애 연구 플랫폼 국가 자산화

### 임상적 영향
- 조기 **스크리닝** 민감도: **≥90%** (조기 발견율 극대화)
- 조기중재 연결율: 15% → **45%** (3배 향상)
- 진단-치료 기간: 24개월 → **12개월** (50% 단축)
- 하위분류 정확도: Macro-F1 ≥0.65 (ASD/ID/CP/Other 구분)
- **설명가능 AI 리포트**: Chain-of-Reasoning 기반 자연어 근거 제공
  - 임상의 의사결정 지원 (판단 근거 확인 가능)
  - 보호자 상담용 간소화 설명 자동 생성
  - 의료법 준수: AI 판단의 투명성 확보

### 사회경제적 영향
- 발달장애 조기 발견 시 1인당 평균 **8,000만원** 의료비 절감 (보수적 추정)
- 연간 조기 발견 증가분 5,000명 × 8,000만원 = **4,000억원** 잠재적 사회비용 절감
- 연구인력 직접 고용 10명, 생태계 간접 효과 50명+
- **LLM 기반 의료 AI 규제 선도**: FDA/KFDA 승인 가능한 설명가능 AI 프레임워크 제시
